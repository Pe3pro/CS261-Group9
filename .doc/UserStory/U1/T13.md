U1:T13 ออกแบบ Integration Test ระหว่าง UI กับ API
-
User story U1: นักศึกษาและเจ้าหน้าที่เข้าสู่ระบบด้วย Username และ Password ของสำนักทะเบียน (บัญชี มธ.) เพื่อเข้าใช้งานแอปพลิเคชัน

ขอบเขต
-
- หน้า `login.html` เรียก backend จริง (`docker compose up -d --build`, ตั้ง `TU_API_KEY` ใน `.env`)
- ตรวจด้วย DevTools แท็บ Network / Application (sessionStorage) · TC1–TC5 ดู [T11.md](T11.md)
- ผู้ทดสอบใช้บัญชี มธ. ของตัวเอง ห้ามจดรหัสผ่านลงเอกสาร
