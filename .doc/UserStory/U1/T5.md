U1:T5 Design UI & DTO & API

User story U1: นักศึกษาและเจ้าหน้าที่เข้าสู่ระบบด้วย Username และ Password ของสำนักทะเบียน (บัญชี มธ.) เพื่อเข้าใช้งานแอปพลิเคชัน

UI prototype
-
![.doc/UserStory/U1/U1 Login.png](<U1 Login.png>)

- กรอก Username (รหัสนักศึกษา) และ Password แล้วกด "เข้าสู่ระบบ"
- ถ้า Log in ไม่สำเร็จ จะแสดงกล่องแจ้งเตือนสีแดงใต้ฟอร์ม และให้กรอกใหม่อีกครั้ง
- ถ้า Log in สำเร็จ ระบบจะพาไปหน้าหลักตามบทบาท (นักศึกษา / เจ้าหน้าที่)

API Specification
-
| Method | Endpoint | หน้าที่ |
|---|---|---|
| POST | `/api/auth/login` | ตรวจสอบ Username / Password กับระบบของ มธ. แล้วส่ง Token และ Role กลับ |

**Request body** (`LoginRequest`)
```json
{
  "username": "6512345678",
  "password": "********"
}
```

**Response 200 OK** (`LoginResponse`)
```json
{
  "accessToken": "3f1c9a52-7d0e-4b8a-9a61-2e5b0c4d7f10",
  "tokenType": "Bearer",
  "expiresAt": "2026-10-19T17:00:00Z",
  "username": "6512345678",
  "displayName": "นักศึกษา ทดสอบ",
  "role": "STUDENT"
}
```

**Response เมื่อไม่สำเร็จ** (`ErrorResponse`)

| Status | กรณี | ตัวอย่าง `message` |
|---|---|---|
| 400 Bad Request | ไม่ได้กรอก Username หรือ Password | `กรุณากรอก Username และ Password` |
| 401 Unauthorized | Username หรือ Password ไม่ถูกต้อง | `Username หรือ Password ไม่ถูกต้อง` |
| 502 Bad Gateway | เชื่อมต่อ TU REST API ไม่ได้ | `ไม่สามารถเชื่อมต่อระบบของมหาวิทยาลัยได้ กรุณาลองใหม่อีกครั้ง` |

**External API ที่ Backend เรียกใช้**

| Method | Endpoint | หน้าที่ |
|---|---|---|
| POST | `https://restapi.tu.ac.th/api/v1/auth/Ad/verify` | ตรวจสอบบัญชี มธ. (Header `Application-Key`, body `UserName` / `PassWord`) |

- Application-Key เก็บไว้ใน environment variable `TU_API_KEY` เท่านั้น ห้าม commit ขึ้น Git
- `type` = `student` → Role `STUDENT`, `type` = `employee` → Role `STAFF`
