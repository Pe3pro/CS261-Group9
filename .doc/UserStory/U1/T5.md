U1:T5 Design UI & DTO & API
-
User story U1: นักศึกษาและเจ้าหน้าที่เข้าสู่ระบบด้วย Username และ Password ของสำนักทะเบียน (บัญชี มธ.) เพื่อเข้าใช้งานแอปพลิเคชัน

UI prototype
-
![.doc/UserStory/U1/U1 Login.png](<U1 Login.png>)

- กรอก Username (รหัสนักศึกษา / รหัสบุคลากร) และ Password แล้วกด "เข้าสู่ระบบ"
- ถ้า Log in ไม่สำเร็จ จะแสดงกล่องแจ้งเตือนสีแดงใต้ฟอร์ม (ข้อความจาก `ErrorResponse.message`) และให้กรอกใหม่อีกครั้ง
- ถ้า Log in สำเร็จ ระบบจะพาไปหน้าหลักตาม `role` (นักศึกษา / เจ้าหน้าที่ / อาจารย์ที่ปรึกษา / ผู้ดูแลระบบ)

API Specification
-
| Method | Endpoint | หน้าที่ |
|---|---|---|
| POST | `/api/auth/login` | ตรวจสอบ Username / Password กับระบบของ มธ. แล้วส่ง Token, `userId` และ Role กลับ |

**Request body** (`LoginRequest`)
```json
{
  "username": "6512345678",
  "password": "********"
}
```

**Response 200 OK** (`LoginResponse`)
```json
{
  "accessToken": "3f1c9a52-7d0e-4b8a-9a61-2e5b0c4d7f10",
  "tokenType": "Bearer",
  "expiresAt": "2026-10-19T17:00:00Z",
  "userId": 3,
  "username": "6512345678",
  "fullName": "นักศึกษา ทดสอบ",
  "role": "STUDENT"
}
```

- `userId` คือ `users.id` ในฐานข้อมูล Frontend เก็บไว้ใน `sessionStorage` แล้วส่งเป็น header `X-User-Id` ให้ API ของ U3/U5 (`AccessGuard`) จนกว่าจะเปลี่ยนไปตรวจจาก Token
- `role` ใช้ค่าจาก enum `Role` ที่มีอยู่แล้ว: `STUDENT` / `STAFF` / `ADVISOR` / `ADMIN`

**Response เมื่อไม่สำเร็จ** (`ErrorResponse` ที่ใช้ร่วมกันทุก API, ส่งผ่าน `ApiException` → `ApiExceptionHandler`)

| Status | `code` | กรณี | ตัวอย่าง `message` |
|---|---|---|---|
| 400 Bad Request | `VALIDATION_ERROR` | ไม่ได้กรอก Username หรือ Password | `กรุณากรอก Username และ Password` |
| 401 Unauthorized | `INVALID_CREDENTIALS` | Username หรือ Password ไม่ถูกต้อง | `Username หรือ Password ไม่ถูกต้อง` |
| 403 Forbidden | `FORBIDDEN` | บัญชีถูกปิดใช้งาน (`users.active = false`) | `บัญชีนี้ถูกปิดการใช้งาน กรุณาติดต่อเจ้าหน้าที่` |
| 502 Bad Gateway | `TU_API_UNAVAILABLE` | เชื่อมต่อ TU REST API ไม่ได้ | `ไม่สามารถเชื่อมต่อระบบของมหาวิทยาลัยได้ กรุณาลองใหม่อีกครั้ง` |

```json
{
  "code": "INVALID_CREDENTIALS",
  "message": "Username หรือ Password ไม่ถูกต้อง"
}
```

**External API ที่ Backend เรียกใช้**

| Method | Endpoint | หน้าที่ |
|---|---|---|
| POST | `https://restapi.tu.ac.th/api/v1/auth/Ad/verify` | ตรวจสอบบัญชี มธ. (Header `Application-Key`, body `UserName` / `PassWord`) |

- Application-Key เก็บไว้ใน environment variable `TU_API_KEY` เท่านั้น ห้าม commit ขึ้น Git
- การกำหนด Role
  - ผู้ใช้ใหม่: `type` = `student` → `STUDENT`, `type` = `employee` → `STAFF`
  - ผู้ใช้ที่มีอยู่แล้วในตาราง `users` (เช่น `advisor01` ที่ seed ไว้เป็น `ADVISOR`): **ใช้ role เดิม** ไม่เขียนทับ
