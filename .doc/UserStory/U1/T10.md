เทียบ Sequence Diagram กับโค้ดที่รวมแล้ว
-
| ขั้นใน Sequence Diagram | Component / ไฟล์ | หลักฐาน |
|---|---|---|
| ผู้ใช้กรอก Username / Password แล้วกดเข้าสู่ระบบ | UI: `frontend/login.html`, `frontend/js/login.js` | รูป A, B, C |
| Frontend → `POST /api/auth/login` `{username, password}` | `login.js` → `AuthController` | DevTools Network แถว `login` (รูป A/B) |
| Controller → Service | `AuthController.login()` → `AuthService.login()` | |
| ตรวจกับ TU REST API `POST /api/v1/auth/Ad/verify` (Header `Application-Key`) | `TuApiClient.verify()` อ่าน key จาก `TU_API_KEY` | รูป C (บัญชีจริงผ่าน), รูป B (รหัสผิด → 401) |
| `findByUsername` → มีแล้ว: ใช้ role เดิม / ยังไม่มี: `save` User (+ Student) | DAO: `UserRepository`, `StudentRepository` | ตาราง users / students ด้านล่าง |
| ตอบ `LoginResponse(accessToken, userId, role, ...)` | `LoginResponse` | |
| หน้าเว็บเก็บ session แล้วไปหน้าตาม role | `login.js` → `staff-review.html` (STAFF/ADVISOR) / `check.html` (STUDENT) | รูป A, C |
| ไม่สำเร็จ → `ApiException` → `ApiExceptionHandler` → `ErrorResponse(code, message)` | กล่องแดงใน `login.html` | รูป B |
| หลัง login หน้า U5 เรียก API ด้วย `X-User-Id` = `userId` | `u5.js` + `AccessGuard` | รูป A (โหลดใบสมัครได้) |

วิธีรันทั้งระบบ
-
1. สร้างไฟล์ `.env` ข้าง `docker-compose.yml` ใส่ `TU_API_KEY=<Application-Key ของกลุ่ม>` (ไฟล์อยู่ใน `.gitignore` ห้าม commit)
2. `docker compose up -d --build`
3. เปิด `frontend/login.html` ด้วย Live Server
4. บัญชีทดลอง: `staff01` / `advisor01` / `6609650001` รหัสผ่าน `1234` · บัญชี มธ. จริงใช้รหัสผ่านของมหาวิทยาลัย
