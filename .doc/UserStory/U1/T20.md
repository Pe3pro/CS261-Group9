ปัญหาที่พบ
-
| รายการ | รายละเอียด |
|---|---|
| ข้อที่พบ | UAT-L06 |
| อาการ | ออกจากระบบแล้วกด Back เบราว์เซอร์แสดงหน้าเดิมของผู้ใช้คนเดิม (พบทั้ง 3 คน) |
| สาเหตุ | ตอนออกจากระบบ ระบบลบข้อมูล login ใน sessionStorage แล้ว แต่เบราว์เซอร์นำหน้าเดิมจากแคช (back-forward cache) กลับมาแสดงโดยไม่ได้รันโค้ดตรวจการ login ใหม่ |
| วิธีแก้ที่เสนอ | ใน `js/script.js` และ `js/u5.js` เพิ่ม `window.addEventListener('pageshow', e => { if (e.persisted) location.reload(); })` ให้หน้าโหลดใหม่และตรวจการ login อีกครั้งเมื่อถูกเปิดจากแคช |
| สถานะ | ยังไม่แก้ใน Sprint นี้ · ยกไปเป็นงานใน Sprint ถัดไป |
