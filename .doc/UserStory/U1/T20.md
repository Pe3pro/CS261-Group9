วิธีทดสอบ
-
1. อธิบายสั้น ๆ ว่า "ระบบนี้ใช้บัญชี มธ. เข้าใช้งาน" โดยไม่บอกว่าต้องกดตรงไหน
2. ให้ผู้ทดสอบทำตาม scenario เอง ทีมจับเวลา UAT-L01 และจดจุดที่ผู้ทดสอบติดหรือถาม
3. UAT-L05 ทีมเตรียมให้: ลบ `TU_API_KEY` ใน `.env` แล้ว `docker compose up -d --force-recreate app` เสร็จแล้วใส่ key คืน
4. หลังทดสอบถามผู้ทดสอบ: ข้อความเข้าใจไหม · ยอมรับได้ไหม · อยากให้ปรับอะไร
