U1:T11 ออกแบบ Unit Test Cases ส่วน UI
-
User story U1: นักศึกษาและเจ้าหน้าที่เข้าสู่ระบบด้วย Username และ Password ของสำนักทะเบียน (บัญชี มธ.) เพื่อเข้าใช้งานแอปพลิเคชัน

Test case หลักของ U1 (ใช้อ้างอิงใน T11–T16)
-
| เคส | คำอธิบาย |
|---|---|
| TC1 | นักศึกษา login ด้วยบัญชี มธ. สำเร็จ แล้วเข้าหน้าตรวจสอบคุณสมบัติ |
| TC2 | เจ้าหน้าที่ / อาจารย์ login สำเร็จ แล้วเข้าหน้าตรวจใบสมัครตาม role |
| TC3 | Username หรือ Password ไม่ถูกต้อง ระบบแจ้งเตือนและให้กรอกใหม่ |
| TC4 | ไม่กรอก Username หรือ Password ระบบแจ้งเตือนโดยไม่ส่งไปตรวจ |
| TC5 | ระบบของมหาวิทยาลัยขัดข้อง หรือบัญชีถูกปิดใช้งาน ระบบแจ้งเหตุผลและไม่ให้เข้าใช้งาน |

| TC ID | เคส | Input | Expected result |
|---|---|---|---|
| UI-L01 | – | เปิดหน้า | มีช่อง Username, Password (type password), ปุ่มเข้าสู่ระบบ ไม่มีกล่องแจ้งเตือน |
| UI-L02 | TC4 | Username ว่าง / Password ว่าง / ช่องว่างล้วน | กล่องแดง `กรุณากรอก Username และ Password` ไม่เรียก API |
| UI-L03 | TC1 | `6609650001` + รหัสถูก → server ตอบ 200 STUDENT | POST `/api/auth/login` body `{username, password}` (ตัดช่องว่าง) เก็บ `u1-auth`, `u5-user`, `coop-state.user` แล้วไป `check.html` |
| UI-L04 | TC1 | เหมือน UI-L03 แต่เคยทำถึงขั้น 2 แล้ว | ไป `submit.html` ความคืบหน้าเดิมไม่หาย |
| UI-L05 | TC2 | `staff01` / `advisor01` → 200 STAFF / ADVISOR | ไป `staff-review.html` |
| UI-L06 | TC3 | รหัสผิด → 401 `INVALID_CREDENTIALS` | แสดง message จาก server ล้างช่อง Password ไม่เปลี่ยนหน้า ไม่มี session |
| UI-L07 | TC5 | 403 `FORBIDDEN` / 502 `TU_API_UNAVAILABLE` | แสดง message จาก server ไม่เปลี่ยนหน้า |
| UI-L08 | TC5 | backend ไม่ทำงาน (network error) | `ไม่สามารถเชื่อมต่อระบบได้ กรุณาลองใหม่อีกครั้ง` ปุ่มกดใหม่ได้ |
| UI-L09 | – | กดส่งแล้ว server ยังไม่ตอบ | ปุ่ม disabled ข้อความ `กำลังเข้าสู่ระบบ...` |
| UI-L10 | TC1 | เปิดหน้า login ขณะ token ยังไม่หมดอายุ | ไปหน้าหลักของ role ทันที ไม่เรียก API |
| UI-L11 | – | token หมดอายุ / logout แล้ว | อยู่หน้า login ล้าง `u1-auth`, `u5-user` |
| UI-L12 | – | 200 แต่ไม่มี `userId` / `role` | ไม่ถือว่าสำเร็จ แสดงกล่องแจ้งเตือน |
