U1:T7 Develop UI
-
User story U1: นักศึกษาและเจ้าหน้าที่เข้าสู่ระบบด้วย Username และ Password ของสำนักทะเบียน (บัญชี มธ.) เพื่อเข้าใช้งานแอปพลิเคชัน

UI prototype
-
![.doc/UserStory/U1/U1 Login.png](<U1 Login.png>)

ไฟล์ที่พัฒนา
-
| ไฟล์ | หน้าที่ |
|---|---|
| `frontend/login.html` | หน้า Log in ตาม prototype (ช่อง Username, Password, ปุ่มเข้าสู่ระบบ, กล่องแจ้งเตือนสีแดง) |
| `frontend/js/login.js` | ส่ง `POST /api/auth/login` แสดงข้อความ error จาก server เก็บ session แล้วพาไปหน้าหลักตาม role |
| `frontend/js/script.js` | หน้า check / submit / ranking ใช้ role จาก backend ตัดสินว่าเป็นนักศึกษาหรือเจ้าหน้าที่ · ปุ่มออกจากระบบล้าง token |
| `frontend/js/u5.js` | ปุ่มออกจากระบบของหน้า U5 ล้าง token ของ U1 ด้วย |

การทำงานของหน้า
-
- ไม่กรอก Username หรือ Password → แจ้ง `กรุณากรอก Username และ Password` โดยไม่เรียก API
- กดเข้าสู่ระบบ → ปุ่มกดไม่ได้และขึ้น `กำลังเข้าสู่ระบบ...` จนกว่า server จะตอบ
- สำเร็จ → เก็บข้อมูลใน `sessionStorage` แล้วไปหน้าหลัก
  - `u1-auth` : `accessToken`, `expiresAt`, `userId`, `username`, `fullName`, `role`
  - `u5-user` : `{id, role, name, username}` ให้หน้า U5 ส่ง header `X-User-Id`
  - `coop-state.user` : username ให้หน้า check / submit / ranking (ความคืบหน้าเดิมไม่หาย)
  - `STUDENT` → ขั้นแรกที่ยังทำไม่เสร็จ (`check.html` / `submit.html` / `ranking.html`) · `STAFF` / `ADVISOR` / `ADMIN` → `staff-review.html`
- ไม่สำเร็จ → แสดง `message` จาก `ErrorResponse` ในกล่องสีแดง (401 ล้างช่อง Password ให้กรอกใหม่)
- เชื่อมต่อ backend ไม่ได้ → `ไม่สามารถเชื่อมต่อระบบได้ กรุณาลองใหม่อีกครั้ง`
- เปิดหน้า login ขณะที่ token ยังไม่หมดอายุ (8 ชั่วโมง) → ไปหน้าหลักทันที

Unit test หน้า UI
-
ไฟล์ `frontend/tests/u1.test.js` (Vitest + jsdom จำลอง backend ด้วย fake fetch ไม่ต้องเปิด server)

| TC ID | Scenario | Expected |
|---|---|---|
| UI-L01 | เปิดหน้า login | มีช่อง Username / Password ปุ่มเข้าสู่ระบบ ยังไม่แสดงกล่องแจ้งเตือน |
| UI-L02 | ไม่กรอก Username หรือ Password | แจ้ง `กรุณากรอก Username และ Password` และไม่เรียก API |
| UI-L03 | นักศึกษา login สำเร็จ | POST `/api/auth/login` ถูกต้อง เก็บ session ไป `check.html` |
| UI-L04 | นักศึกษาที่ทำขั้นตอนไปแล้ว | ไปต่อขั้นเดิม ความคืบหน้าไม่หาย |
| UI-L05 | เจ้าหน้าที่ / อาจารย์ login สำเร็จ | ไป `staff-review.html` |
| UI-L06 | รหัสผ่านผิด (401) | แสดงข้อความจาก server ล้างช่อง Password ไม่เปลี่ยนหน้า |
| UI-L07 | บัญชีถูกปิด (403) / ระบบ มธ. ขัดข้อง (502) | แสดงข้อความจาก server |
| UI-L08 | เชื่อมต่อ backend ไม่ได้ | `ไม่สามารถเชื่อมต่อระบบได้ กรุณาลองใหม่อีกครั้ง` กดใหม่ได้ |
| UI-L09 | ระหว่างรอ server | ปุ่ม disabled และขึ้น `กำลังเข้าสู่ระบบ...` |
| UI-L10 | login ค้างอยู่ token ยังไม่หมดอายุ | ไปหน้าหลักทันที |
| UI-L11 | token หมดอายุ / logout แล้ว | อยู่หน้า login และล้างข้อมูลเก่า |
| UI-L12 | response 200 แต่ข้อมูลไม่ครบ | ไม่ถือว่าสำเร็จ |
