U1:T21 : Deployment Demo ระบบให้ User ดู
-
User story U1: นักศึกษาและเจ้าหน้าที่เข้าสู่ระบบด้วย Username และ Password ของสำนักทะเบียน (บัญชี มธ.) เพื่อเข้าใช้งานแอปพลิเคชัน

นำเสนอการทำงานของระบบ Login (นศ./จนท.) ให้ผู้ใช้ดู และรวบรวม feedback เพื่อนำไปปรับปรุงใน Sprint ถัดไป

เตรียมก่อน demo
-
- [ ] `git checkout Develop` และ `git pull` ให้ได้โค้ดล่าสุด
- [ ] ไฟล์ `.env` ข้าง `docker-compose.yml` มี `TU_API_KEY=...` (ไม่ commit)
- [ ] `docker compose up -d --build`
- [ ] เปิด `frontend/login.html` ด้วย Live Server แล้วลอง login `staff01` / `1234` ให้ผ่าน 1 ครั้ง แล้วออกจากระบบ
- [ ] test ผ่าน: `cd demo` แล้ว `./mvnw test` และ `npm run test:ui`
- [ ] ให้ผู้ชมที่เป็นนักศึกษาเตรียมบัญชี มธ. ของตัวเอง (ทีมไม่ดู ไม่จดรหัสผ่าน)
