ส่วนที่ 2: Integration Test UI กับ API จริง (ตาม T13)
-
รันด้วยสคริปต์ `tools/u1-t17-run.mjs` (Playwright) ทุกเคสใช้ browser context ใหม่ (sessionStorage ว่าง)

```powershell
docker compose up -d --build
# บัญชี มธ. ส่งผ่าน environment variable (Read-Host -AsSecureString) ไม่บันทึกลงไฟล์
node tools/u1-t17-run.mjs
```
