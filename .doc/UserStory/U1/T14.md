U1:T14 ออกแบบ Integration Test ระหว่าง API กับ DAO
-
User story U1: นักศึกษาและเจ้าหน้าที่เข้าสู่ระบบด้วย Username และ Password ของสำนักทะเบียน (บัญชี มธ.) เพื่อเข้าใช้งานแอปพลิเคชัน

ขอบเขต
-
- `AuthController` → `AuthService` → `UserRepository` / `StudentRepository` → ฐานข้อมูล โดยไม่ใช้หน้าเว็บ
- รันอัตโนมัติด้วย `@SpringBootTest` + MockMvc + H2 (ล้างตาราง users / students ก่อนทุกข้อ)
- TU REST API เป็นระบบภายนอก จึงจำลองด้วย `@MockitoBean TuApiClient` · TC1–TC5 ดู [T11.md](T11.md)
