U1 มี Sequence Diagram เดียว (login) ดู [T6.md](T6.md) · ทดสอบทั้งระบบด้วย `docker compose up -d --build` + Live Server แล้วตรวจทั้งหน้าจอ, DevTools และ MySQL · TC1–TC5 ดู [T11.md](T11.md)

Test cases

| TC ID | เคส | เส้นทางใน Sequence Diagram | Input / ขั้นตอน | Expected result |
|---|---|---|---|---|
| ST-L01 | TC1 | สำเร็จ → ผู้ใช้ใหม่ → save User + Student | นักศึกษาที่ยังไม่เคย login กรอกบัญชี มธ. | 200 STUDENT ไป `check.html` · users +1 (password_hash NULL) · students +1 |
