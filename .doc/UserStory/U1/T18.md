U1:T18 ทดสอบ Integration ระหว่าง API กับ DAO
-
User story U1: นักศึกษาและเจ้าหน้าที่เข้าสู่ระบบด้วย Username และ Password ของสำนักทะเบียน (บัญชี มธ.) เพื่อเข้าใช้งานแอปพลิเคชัน

รันกรณีทดสอบที่ออกแบบไว้ใน [T14.md](T14.md) (IT-AD-L01–L07) · Test case หลัก TC1–TC5 ดู [T11.md](T11.md)

ขอบเขตและวิธีทดสอบ
-
| รายการ | ค่า |
|---|---|
| เส้นทางที่ทดสอบ | `POST /api/auth/login` → `AuthController` → `AuthService` → `UserRepository` / `StudentRepository` → ฐานข้อมูล |
| ไฟล์ทดสอบ | `demo/src/test/java/com/example/demo/integration/AuthApiDaoIntegrationTest.java` |
| เครื่องมือ | JUnit 5 · `@SpringBootTest` + `@AutoConfigureMockMvc` (เรียก API จริงใน Spring context ไม่ผ่านหน้าเว็บ) · AssertJ |
| ฐานข้อมูล | H2 in-memory (`MODE=MySQL`, `ddl-auto=create-drop`) · ปิด `DemoDataSeeder` · ล้างตาราง `users` / `students` ก่อนทุกเคส |
| ระบบภายนอก | TU REST API จำลองด้วย `@MockitoBean TuApiClient` (ไม่ส่งรหัสผ่านจริงออกนอกระบบ) |
| การตรวจ | ตรวจทั้ง HTTP response (status, `code`, `message`, `role`, `userId`) และข้อมูลในตารางหลังเรียก API ผ่าน repository |

คำสั่งที่ใช้ (จากโฟลเดอร์ `demo`)

```powershell
.\mvnw.cmd test -Dtest=AuthApiDaoIntegrationTest
```
