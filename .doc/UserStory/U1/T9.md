- U1 **ใช้ Entity และ Repository ที่มีอยู่แล้ว** (`entity/User`, `entity/Role`, `entity/Student`, `dao/UserRepository`, `dao/StudentRepository`) ไม่สร้างตารางใหม่

Unit test DAO
-
ไฟล์ `demo/src/test/java/com/example/demo/dao/LoginRepositoryTest.java` (`@DataJpaTest` + ฐานข้อมูล H2 ล้างข้อมูลทุก test ไม่ต้องเปิด MySQL)

| TC ID | Scenario | Method | Expected |
|---|---|---|---|
| DAO-L01 | บันทึกผู้ใช้ใหม่จากการ login | `save`, `findByUsername` | ได้ `id`, `active = true`, มี `createdAt`, ค้นด้วย username ได้ role STUDENT |
| DAO-L02 | อัปเดตชื่อ/อีเมลผู้ใช้เดิม | `findByUsername`, `save` | `id` และ `role` (ADVISOR) ไม่เปลี่ยน ชื่อ/อีเมลใหม่ถูกบันทึก ไม่มีแถวเพิ่ม |
| DAO-L03 | Student ผูกกับ User | `StudentRepository.findByUserId`, `findByStudentId` | ค้นได้ทั้ง 2 ทาง · userId ที่ไม่มีได้ empty |
| DAO-L04 | สร้าง Student ซ้ำให้ User เดิม | `saveAndFlush` | `DataIntegrityViolationException` (user_id unique) |
| DAO-L05 | ไม่เก็บรหัสผ่าน | `save` | `password_hash` เป็น null |

- เคส username ซ้ำ (`DAO-U03`) และค้นผู้ใช้ (`DAO-U02`) มีอยู่แล้วใน `UserRepositoryTest` ของ U5 ใช้ร่วมกันได้

```powershell
cd demo
.\mvnw.cmd test -Dtest=LoginRepositoryTest
```
