| ขั้นใน Sequence Diagram | Component / ไฟล์ | หลักฐาน |
|---|---|---|

| ① เปิดใช้งาน `POST /api/forms/{id}/publish` (ฉบับเดิม → ARCHIVED) | `FormTemplateService.publish()` | รูป B |

| ③ ไม่อนุมัติแต่ไม่ใส่เหตุผล → 400 / ตัดสินซ้ำ → 409 | `ApiException` → `ApiExceptionHandler` → `ErrorResponse(code, message)` | รูป E |

| ⑤ นักศึกษาดูแจ้งเตือน `GET /api/notifications` + `PATCH /{id}/read` | `notifications.html` → `NotificationController` → `NotificationService` | รูป G |
| ① ปิดรับก่อนกำหนด `POST /api/forms/{id}/close` | `FormTemplateController.close()` → `FormTemplateService.close()` → `FormTemplateRepository.save` | รูป H |
| U3 → ② แนบไฟล์ช่องอื่น `POST /api/requests/{id}/documents?fieldId=` · submit ตรวจครบทุกช่องไฟล์ | `submit.html` + `js/script.js` → `RequestController` → `DocumentService.upload(…, fieldId, …)` · `RequestService.requireDocuments()` | รูป I |
| U3 submit → แจ้งเจ้าหน้าที่ | `RequestService.submit()` → `NotificationService.notifyStaffSubmitted()` → `NotificationRepository.save` | ตาราง notifications |
| ② จำนวนทุกสถานะ / ป้ายเตือน / Excel | `ApplicationReviewController` → `ApplicationReviewService.getSummary()`, `attention()`, `exportCsv()` | รูป J |
| ③ ส่งกลับพร้อมช่องที่ต้องแก้ + เก็บค่าเดิม | `ApprovalService.withFieldsToFix()` → `FormFieldRepository` · `snapshotAnswers()` → `AnswerSnapshotRepository.save` | รูป K |
| ③ อนุมัติหลายใบ `POST /api/approvals/bulk` | `BulkApprovalController` → `BulkApprovalService` → `ApprovalService.decide()` ทีละใบ | รูป L |
| ② ค่าเดิมของฉบับแก้ | `ApplicationReviewService.getDetail()` → `AnswerSnapshotRepository.findByApprovalId` → `AnswerResponse.previousValue` | รูป K |
| เตือนนักศึกษาก่อนหมดเขต (ทุกวัน 08:00) | `SchedulingConfig` → `CorrectionReminderJob` → `NotificationService.remindCorrection()` → `NotificationRepository` | ตาราง notifications |

ข้อมูลในฐานข้อมูลหลังรัน (MySQL)
-
```sql
SELECT id, status, version FROM applications;
SELECT application_id, approval_level, decision, comment FROM approvals;
SELECT user_id, title, is_read FROM notifications ORDER BY id;
SELECT approval_id, form_field_id, field_value FROM answer_snapshots;
SELECT application_id, form_field_id, file_name FROM documents;
```

| ตาราง | ที่ต้องเห็น | ผล |
|---|---|---|
| applications | ใบสมัครของสมชาย = `APPROVED` · ของสมหญิง = `SUBMITTED` | |
| approvals | 2 แถวของสมชาย: STAFF APPROVE, ADVISOR APPROVE | |
| notifications | อาจารย์ 1 แถว (มีใบสมัครรอพิจารณา) · สมชาย 2 แถว | |
| notifications (H–L) | เจ้าหน้าที่ได้ `APPLICATION_SUBMITTED` ทุกครั้งที่มีคำร้องใหม่ / ฉบับแก้ | |
| answer_snapshots (K) | มีแถวของการส่งกลับในรูป K ครบทุกช่องที่นักศึกษาเคยตอบ | |
| documents (I) | คำร้องในรูป I มี 2 แถว: `form_field_id` ว่าง (Transcript) และ id ของช่องไฟล์ที่ 2 | |
