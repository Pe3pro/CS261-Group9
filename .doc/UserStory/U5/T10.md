เทียบ Sequence Diagram กับโค้ดที่รวมแล้ว
-
| ขั้นใน Sequence Diagram | Component / ไฟล์ | หลักฐาน |
|---|---|---|
| ผู้ใช้ login แล้วหน้าเว็บรู้ `userId` / `role` | `login.html` + `js/login.js` (U1) → เก็บ `u5-user` · `js/u5.js` ส่ง `X-User-Id` ทุก request | รูป A |
| ① เจ้าหน้าที่สร้างแบบฟอร์ม `POST /api/forms` | `staff-forms.html` → `FormTemplateController.create()` → `FormTemplateService` → `FormTemplateRepository`, `FormFieldRepository` | รูป B |
| ① เปิดใช้งาน `POST /api/forms/{id}/publish` (ฉบับเดิม → ARCHIVED) | `FormTemplateService.publish()` | รูป B |
| ② รายการรอตรวจ `GET /api/applications?status=SUBMITTED` | `staff-review.html` → `ApplicationReviewController` → `ApplicationReviewService` → `ApplicationRepository`, `StudentRepository`, `DocumentRepository` | รูป A |
| ② รายละเอียด `GET /api/applications/{id}/detail` | `ApplicationReviewService.getDetail()` + `FormResponseRepository`, `ApprovalRepository` | รูป C |
| ③ เจ้าหน้าที่ตัดสิน `POST /api/approvals/{id}/decision` | `ApprovalController` → `ApprovalService.decide()` → `ApprovalRepository.save`, `ApplicationRepository.save` (`@Version`) | รูป D |
| ③ ไม่อนุมัติแต่ไม่ใส่เหตุผล → 400 / ตัดสินซ้ำ → 409 | `ApiException` → `ApiExceptionHandler` → `ErrorResponse(code, message)` | รูป E |
| ③ แจ้งเตือนอาจารย์ + นักศึกษา | `NotificationService.notifyAfterDecision()` → `NotificationRepository.save` | ตาราง notifications |
| ④ อาจารย์ตัดสิน `UNDER_REVIEW` → `APPROVED` | `ApprovalService.decide()` (level = ADVISOR) | รูป F |
| ⑤ นักศึกษาดูแจ้งเตือน `GET /api/notifications` + `PATCH /{id}/read` | `notifications.html` → `NotificationController` → `NotificationService` | รูป G |

วิธีรันทั้งระบบ
-
1. `docker compose down -v` (ล้างฐานข้อมูลให้ `DemoDataSeeder` ใส่ข้อมูลตัวอย่างใหม่: แบบฟอร์ม 1 ฉบับ, ใบสมัคร `SUBMITTED` 2 ใบ)
2. `docker compose up -d --build`
3. เปิด `frontend/login.html` ด้วย Live Server
4. บัญชีทดลอง รหัสผ่าน `1234`: `staff01` (เจ้าหน้าที่) · `advisor01` (อาจารย์) · `6609650001` (นักศึกษา สมชาย)

ข้อมูลในฐานข้อมูลหลังรัน (MySQL)
-
```sql
SELECT id, status, version FROM applications;
SELECT application_id, approval_level, decision, comment FROM approvals;
SELECT user_id, title, is_read FROM notifications ORDER BY id;
```

| ตาราง | ที่ต้องเห็น | ผล |
|---|---|---|
| applications | ใบสมัครของสมชาย = `APPROVED` · ของสมหญิง = `SUBMITTED` | |
| approvals | 2 แถวของสมชาย: STAFF APPROVE, ADVISOR APPROVE | |
| notifications | อาจารย์ 1 แถว (มีใบสมัครรอพิจารณา) · สมชาย 2 แถว | |
