API Specification
-
Method      Endpoint                                 หน้าที่

GET         /api/applications?status=SUBMITTED       เจ้าหน้าที่ดูใบสมัครที่รอตรวจ

GET         /api/applications?status=ADVISOR_REVIEW  อาจารย์ดูใบสมัครที่รอพิจารณา
