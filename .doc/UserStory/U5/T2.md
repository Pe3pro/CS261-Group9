API Specification
-
ทุก request (ยกเว้น `/api/users/{username}`) ส่ง header `X-User-Id` = `userId` ที่ได้จาก `POST /api/auth/login` (U1) · error ทุกตัวตอบเป็น `{"code": "...", "message": "..."}`

| Method | Endpoint | ผู้ใช้ | Request | Response | หน้าที่ |
|---|---|---|---|---|---|
| GET | /api/applications?status=SUBMITTED | เจ้าหน้าที่ | – | List&lt;ApplicationReviewResponse&gt; | ดูใบสมัครที่รอตรวจ |
| GET | /api/applications?status=UNDER_REVIEW | อาจารย์ | – | List&lt;ApplicationReviewResponse&gt; | ดูใบสมัครที่รอพิจารณา |
| GET | /api/applications/summary | เจ้าหน้าที่, อาจารย์ | – | Map&lt;ApplicationStatus, Long&gt; | จำนวนคำร้องทุกสถานะ (ตัวเลขบนแท็บ · อาจารย์นับเฉพาะนักศึกษาของตน) |
| GET | /api/applications/export?status= | เจ้าหน้าที่, อาจารย์ | – | ไฟล์ CSV (`text/csv`) | ดาวน์โหลดรายการเป็น Excel · ไม่ระบุ status = ทุกสถานะยกเว้นฉบับร่าง |
| GET | /api/applications/{id}/detail | เจ้าหน้าที่, อาจารย์ | – | ApplicationDetailResponse | ดูข้อมูลนักศึกษา คำตอบทุกช่อง (ช่องไฟล์ = ชื่อไฟล์ · ช่องที่แก้หลังส่งกลับมีค่าเดิม) เอกสาร และประวัติการพิจารณา |
| POST | /api/approvals/{id}/decision | เจ้าหน้าที่, อาจารย์ | ApprovalRequest | ApprovalResponse | อนุมัติ / ส่งกลับแก้ไข / ปฏิเสธ (ไม่อนุมัติต้องมีเหตุผล · ส่งกลับระบุช่องที่ต้องแก้ได้) |
| POST | /api/approvals/bulk | เจ้าหน้าที่, อาจารย์ | BulkApprovalRequest | BulkApprovalResponse | อนุมัติหลายใบพร้อมกัน (ไม่เกิน 100) · ใบที่อนุมัติไม่ได้ถูกข้ามพร้อมเหตุผล |
| GET | /api/notifications | ทุกคน | – | List&lt;NotificationResponse&gt; | แจ้งเตือนของผู้ใช้ที่ login |
| PATCH | /api/notifications/{id}/read | เจ้าของแจ้งเตือน | – | NotificationResponse | ทำเครื่องหมายว่าอ่านแล้ว |
| GET | /api/forms | เจ้าหน้าที่ | – | List&lt;FormTemplateResponse&gt; | ดูแบบฟอร์มคำร้องทุกฉบับ |
| GET | /api/forms/{id} | เจ้าหน้าที่ | – | FormTemplateResponse | ดูแบบฟอร์ม 1 ฉบับ |
| POST | /api/forms | เจ้าหน้าที่ | FormTemplateRequest | FormTemplateResponse (201) | สร้างแบบฟอร์มฉบับร่าง |
| PUT | /api/forms/{id} | เจ้าหน้าที่ | FormTemplateRequest | FormTemplateResponse | แก้ฉบับร่าง |
| POST | /api/forms/{id}/new-version | เจ้าหน้าที่ | – | FormTemplateResponse (201) | สร้างฉบับใหม่จากฉบับเดิม |
| POST | /api/forms/{id}/publish | เจ้าหน้าที่ | – | FormTemplateResponse | เปิดใช้งาน (ฉบับเดิมเลิกใช้) |
| POST | /api/forms/{id}/close | เจ้าหน้าที่ | – | FormTemplateResponse | ปิดรับคำร้องก่อนกำหนด (วันหมดเขต = เวลานี้) |
| POST | /api/requests/{id}/documents?fieldId= | นักศึกษา (หน้า U3) | ไฟล์ PDF (multipart `file`) | DocumentResponse (201) | แนบไฟล์ให้ช่องแนบไฟล์ที่ระบุ · ไม่ใส่ `fieldId` = Transcript แบบเดิม |
| GET | /api/users/{username} | – | – | UserResponse | หา id / role จาก username ที่ login ไว้ |

![alt text](<US5-T2 API Spec.png>)

DTO ที่เพิ่ม / เปลี่ยน (ของเดิมยังใช้ได้เหมือนเดิม เพราะ field ใหม่ไม่บังคับ)
-
| DTO | field ที่เพิ่ม | ความหมาย |
|---|---|---|
| ApplicationReviewResponse | `attention` | `OVERDUE` (รอนาน) / `DEADLINE_SOON` (ใกล้หมดเขต) / `null` |
| ApprovalRequest | `fieldIds: List<Long>` | ช่องที่ต้องแก้ ใช้ตอน `RETURN` เท่านั้น |
| AnswerResponse | `fieldId`, `previousValue` | id ของช่อง · ค่าก่อนถูกส่งกลับ (มีเฉพาะช่องที่นักศึกษาแก้) |
| DocumentResponse | `formFieldId` | ไฟล์นี้ตอบช่องแนบไฟล์ไหน (`null` = Transcript เดิม) |
| BulkApprovalRequest (ใหม่) | `applicationIds: List<Long>` | คำร้องที่จะอนุมัติ |
| BulkApprovalResponse (ใหม่) | `approved: List<Long>`, `skipped: List<{applicationId, reason}>` | ผลแต่ละใบ |

![alt text](<US5-T2 DTO.png>)

สถานะใบสมัคร: `SUBMITTED` → (เจ้าหน้าที่อนุมัติ) `UNDER_REVIEW` → (อาจารย์อนุมัติ) `APPROVED` · ส่งกลับแก้ไข = `NEED_CORRECTION` · ปฏิเสธ = `REJECTED`
