U5:T21 : Deployment Demo ระบบให้ User ดู
-
User story U5: เจ้าหน้าที่ตรวจสอบใบสมัครสหกิจของนักศึกษา แล้วอนุมัติหรือส่งกลับแก้ไข --> จากนั้นอาจารย์พิจารณาอนุมัติ และระบบแจ้งผลให้นักศึกษา

เตรียมก่อน demo
-
- [ ] `git checkout Develop` และ `git pull` ให้ได้โค้ดล่าสุด
- [ ] `docker compose down -v` แล้ว `docker compose up -d --build` (ข้อมูลตัวอย่าง: แบบฟอร์ม 1 ฉบับ, ใบสมัครรอตรวจของสมชายและสมหญิง)
- [ ] เปิด `frontend/login.html` ด้วย Live Server ลอง login `staff01` / `1234` ให้ผ่าน 1 ครั้ง แล้วออกจากระบบ
- [ ] test ผ่าน: `./mvnw test` และ `npm run test:ui`
- [ ] แผนสำรอง: ถ้า backend เปิดไม่ได้ ใช้ `staff-review.html?demo=1` (ข้อมูลตัวอย่างในเบราว์เซอร์) แต่ต้องบอกผู้ชมว่าเป็นโหมดตัวอย่าง

ข้อจำกัดที่ต้องแจ้งผู้ชม
-
- ใบสมัครใน demo มาจาก `DemoDataSeeder` จนกว่า U3 (ยื่นคำร้อง) จะบันทึกใบสมัครเข้าฐานข้อมูลจริง
- ปุ่ม "ดูไฟล์" ต้องรอ API เอกสารของ U3
- Email ส่งเข้า Mailpit (กล่องจดหมายจำลองใน docker compose) ไม่ได้ส่งออกไปนอกเครื่อง · ถ้าส่งไม่สำเร็จ ผลการพิจารณายังบันทึกครบ
- นักศึกษาที่ยังไม่ได้กำหนดอาจารย์ที่ปรึกษา (`students.advisor_id` ว่าง) อาจารย์จะไม่เห็นคำร้องนั้น · นักศึกษาทดลองทุกคนอยู่ในความดูแลของ advisor01
