ขั้นตอนการรัน (รอบที่ 1)
-
1. `docker compose down -v` แล้ว `docker compose up -d --build` รอจน `GET /api/companies` ตอบ 200
2. ส่ง request ตาม test case ด้วย `curl.exe -s -i -H "X-User-Id: <id>" ...` (PUT ส่ง body จากไฟล์ `body.json`)
3. หลัง PUT ตรวจตาราง `docker exec cs261-db mysql -uroot -proot1234 cs261db -e "SELECT student_id, company_id, rank_no FROM company_rankings;"`
4. ข้อ 2 ปิดทุกบริษัทด้วย `UPDATE companies SET status='CLOSED';` แล้วรีเซ็ตข้อมูลด้วย `docker compose down -v` / `up -d --build`
