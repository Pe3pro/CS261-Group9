ขั้นตอนการรัน
-
1. `docker compose down -v` แล้ว `docker compose up -d --build`
2. เปิด http://localhost:8081/login.html → login → ไปหน้าจับคู่บริษัท
3. เปิด DevTools แท็บ Network ติ๊ก Keep log แล้วรีเฟรชหน้า
4. ทำตามขั้นตอนใน Sequence Diagram แล้วตรวจ 3 จุด: หน้าจอ, แท็บ Network และข้อมูลใน MySQL
5. ส่ง request ตรงเข้า API ด้วย `curl.exe -i -H "X-User-Id: 3" ...`
6. ดูข้อมูลใน MySQL: `docker exec -it cs261-db mysql -uroot -proot1234 cs261db -e "SHOW TABLES; SELECT * FROM companies;"`


รันตาม test cases T15
-
| ลำดับ | ขั้นตอนใน Sequence Diagram | Frontend → API | API → Service → Database | Input | ผลที่คาดหวัง | ผลจริง (หน้าจอ / Network / ฐานข้อมูล) | ผล |
|---|---|---|---|---|---|---|---|
| 1 | นักศึกษาดูบริษัทที่เปิดรับ | GET /api/companies | ค้นหาบริษัท → ดึงบริษัทที่เปิดรับ | - | ได้รายชื่อบริษัท (Company List) และหน้าเว็บแสดงบริษัท | หน้าจอ: แสดงบริษัท A–D ที่เขียนไว้ใน ranking.html · Network: ไม่มี request `GET /api/companies` · API (curl): 200 ได้ 6 บริษัท OPEN (SCB TechX, Agoda Services, KBTG, LINE MAN Wongnai, Bitkub, True Digital Group) · ฐานข้อมูล: ตาราง `companies` มี 7 แถว (OPEN 6 + PTT Digital CLOSED) API ตัดบริษัท CLOSED ออกถูกต้อง แต่หน้าเว็บไม่ได้ใช้ข้อมูลนี้ | ❌ ไม่ผ่าน |
| 2 | เลือกบริษัทและดูตำแหน่ง | GET /api/companies/{id}/positions | ค้นหาตำแหน่ง → ดึงตำแหน่งที่เปิดรับ | id ของบริษัท | ได้ Position List และหน้าเว็บแสดงตำแหน่ง | หน้าจอ: เลือกบริษัท A แล้วไม่มีส่วนแสดงตำแหน่ง · Network: ไม่มี request ใหม่ · API (curl): 404 Not Found | ❌ ไม่ผ่าน |
| 3 | กรอกใบสมัคร | POST /api/applications | สร้างใบสมัคร → บันทึกใบสมัคร | ข้อมูลใบสมัคร | ได้ Application ID และ 201 Created | หน้าจอ: หน้า ranking ไม่มีขั้นกรอกใบสมัคร · Network: ไม่มี request `POST /api/applications` · API (curl): 405 Method Not Allowed (`Allow: GET`) ไม่มี POST สำหรับสร้างใบสมัครที่ path นี้ | ❌ ไม่ผ่าน |
| 4 | เลือกบริษัทและจัดอันดับ | PUT /api/applications/{id}/choices | ตรวจสอบและบันทึกตัวเลือก → บันทึกอันดับ | id ของใบสมัคร + อันดับที่เลือก | บันทึกสำเร็จ → Success → 200 OK | หน้าจอ: ตั้ง A = 1, B = 2, C = 3 กดยืนยันแล้วขึ้น "สำเร็จ บันทึกลำดับเรียบร้อยแล้ว" · Network: ไม่มี request `PUT /choices` · API (curl): 404 Not Found · ฐานข้อมูล: ไม่มีตาราง `application_choices` (มีตาราง `company_rankings` แทน) อันดับที่เลือกไม่ได้ถูกบันทึก | ❌ ไม่ผ่าน |
| 5 | แสดงตัวเลือกที่บันทึกแล้ว | - | - | ผลจากข้อ 4 | หน้าเว็บแสดงตัวเลือกที่บันทึกแล้ว | หน้าจอ: กล่อง "ลำดับที่เลือก" แสดง 1. บริษัท A, 2. บริษัท B, 3. บริษัท C แต่เป็นข้อมูลในเบราว์เซอร์ ไม่ได้มาจากฐานข้อมูล (ข้อ 4 ไม่ได้บันทึก) | ❌ ไม่ผ่าน |
