U4:T11 : ออกแบบ Unit Test Cases ส่วน UI (ระบบจับคู่บริษัท (จัดอันดับ))
-
ออกแบบ test cases สำหรับทดสอบหน้าจอแต่ละหน้าของระบบจับคู่บริษัท (จัดอันดับ)
-


หน้าจอที่ทดสอบ
-
![Figma Ranking](<U4 Ranking.png>)


ระบุ test cases ของแต่ละหน้า
-
| ลำดับ | หน้า | ส่วนที่ทดสอบ |
|---|---|---|
| 1 | ranking.html | แสดงรายชื่อบริษัท |
| 2 | ranking.html | dropdown เลือกอันดับ |
| 3 | ranking.html | กล่อง "ลำดับที่เลือก" เรียงตามอันดับ |
| 4 | ranking.html | ยกเลิกการเลือก |
| 5 | ranking.html | ปุ่ม "ยืนยันการเลือก" กรณีไม่ได้เลือก |
| 6 | ranking.html | ปุ่ม "ยืนยันการเลือก" กรณีอันดับซ้ำ |
| 7 | ranking.html | ปุ่ม "ยืนยันการเลือก" กรณีถูกต้อง |
| 8 | ranking.html | ซ่อนข้อความแจ้งผลเมื่อเปลี่ยนอันดับ |
| 9 | ranking.html | จำอันดับที่เลือกไว้ |


เขียน input / expected result
-
| ลำดับ | Input | ผลที่คาดหวัง |
|---|---|---|
| 1 | เปิดหน้า ranking | แสดงบริษัท A–D และกล่องลำดับที่เลือกขึ้น "ยังไม่ได้เลือก" |
| 2 | กด dropdown ของบริษัท A | มีตัวเลือก "- ไม่เลือก -", อันดับ 1, อันดับ 2, อันดับ 3 |
| 3 | บริษัท A = อันดับ 2, บริษัท B = อันดับ 1 | กล่องลำดับที่เลือกแสดง "1. บริษัท B" แล้ว "2. บริษัท A" |
| 4 | เปลี่ยนบริษัท A กลับเป็น "- ไม่เลือก -" | บริษัท A หายจากกล่องลำดับที่เลือก |
| 5 | ไม่เลือกบริษัทเลย แล้วกด "ยืนยันการเลือก" | แสดง "ไม่สำเร็จ" และ "กรุณาเลือกบริษัทอย่างน้อย 1 แห่ง" |
| 6 | บริษัท A = อันดับ 1, บริษัท B = อันดับ 1 แล้วกดยืนยัน | แสดง "ไม่สำเร็จ" และ "มีลำดับซ้ำกันมากกว่า 1 บริษัท กรุณาเลือกลำดับใหม่" |
| 7 | บริษัท A = 1, B = 2, C = 3 แล้วกดยืนยัน | แสดง "สำเร็จ บันทึกลำดับเรียบร้อยแล้ว" |
| 8 | หลังมีข้อความแจ้งผล เปลี่ยนอันดับใหม่ | ข้อความสำเร็จ / ไม่สำเร็จถูกซ่อน |
| 9 | เลือกอันดับแล้วออกจากหน้า แล้วกลับมาใหม่ | dropdown ยังแสดงอันดับเดิม |
