เขียน input / expected result
-
| ลำดับ | Input | ผลที่คาดหวัง |
|---|---|---|
| 1 | เปิดหน้า ranking | เรียก `GET /api/companies` พร้อม header `X-User-Id` · แสดง 5 ช่องอันดับ และ "เลือกแล้ว 0 จาก 5 อันดับ" |
| 2 | คลิกช่องอันดับ 1 | แสดงบริษัทที่เปิดรับจาก API ครบทุกบริษัท |
| 3 | พิมพ์ "kb" ในช่องอันดับ 1 แล้วกด Enter | เหลือเฉพาะ KBTG · KBTG เป็นอันดับ 1 · ตัวนับเป็น "เลือกแล้ว 1 จาก 5 อันดับ" |
| 4 | อันดับ 1 = KBTG แล้วคลิกช่องอันดับ 2 | ไม่มี KBTG ในรายการ · มีข้อความ "ไม่แสดงบริษัทที่เลือกในอันดับอื่นแล้ว (KBTG)" |
| 5 | กด "ล้าง ✕" ที่อันดับ 1 | อันดับ 1 กลับเป็นช่องค้นหา |
| 6 | เลือก 2 อันดับแล้วกด "ล้างทั้งหมด" | ทุกอันดับว่าง · ตัวนับเป็น "เลือกแล้ว 0 จาก 5 อันดับ" |
| 7 | เลือก 1 อันดับแล้วกด "ยืนยันการเลือก" | แสดง "ไม่สำเร็จ" และ "กรุณาเลือกบริษัทให้ครบ 5 อันดับ (เลือกแล้ว 1 อันดับ)" · ไม่ส่ง PUT |
| 8 | เลือก Bitkub, SCB TechX, Agoda Services, LINE MAN Wongnai, True Digital Group แล้วกดยืนยัน | ส่ง `PUT /api/students/me/company-ranking` `{"companyIds":[5,1,2,4,6]}` · แสดง "สำเร็จ บันทึกลำดับเรียบร้อยแล้ว" |
| 9 | API มีอันดับที่บันทึกไว้แล้ว เปิดหน้าใหม่ | แสดงบริษัทในอันดับ 1–5 ตามที่บันทึก · "เลือกแล้ว 5 จาก 5 อันดับ" |
| 10 | API ตอบ 409 `RANKING_LOCKED` ตอนกดยืนยัน | แสดง "คุณยื่นคำร้องแล้ว ไม่สามารถแก้ไขอันดับบริษัทได้" · ปุ่มยืนยันกดไม่ได้ · ไม่มีปุ่มล้าง |
| 11 | backend ไม่ตอบ | แสดง "ไม่สามารถเชื่อมต่อระบบได้ กรุณาลองใหม่อีกครั้ง" |
