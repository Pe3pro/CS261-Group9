U4:T11 : ออกแบบ Unit Test Cases ส่วน UI (ระบบจับคู่บริษัท (จัดอันดับ))
-
ออกแบบ test cases สำหรับทดสอบหน้าจอแต่ละหน้าของระบบจับคู่บริษัท (จัดอันดับ)
-


หน้าจอที่ทดสอบ (Figma : Ranking)
-
![Figma Ranking](<U4 Ranking.png>)


View Class : CompanyChoiceView (หน้าเลือกบริษัทและตำแหน่ง 5 อันดับ)
-
| Attributes | Methods |
|---|---|
| availableCompanies: List&lt;Company&gt; | loadAvailableCompanies(): void |
| selectedChoices: List&lt;ApplicationChoice&gt; | selectCompany(): void |
| maxChoices: Integer | selectPosition(): void |
| | reorderChoices(): void |
| | validateChoices(): Boolean |
| | saveChoices(): void |


ระบุ test cases ของแต่ละหน้า
-
| ลำดับ | หน้า | Method ที่ทดสอบ | Input | ผลที่คาดหวัง |
|---|---|---|---|---|
| 1 | CompanyChoiceView | loadAvailableCompanies() | เปิดหน้า Ranking | แสดงรายชื่อบริษัทที่เปิดรับ (availableCompanies) |
| 2 | CompanyChoiceView | selectCompany() | เลือกบริษัท 1 บริษัท | แสดงตำแหน่งของบริษัทที่เลือก |
| 3 | CompanyChoiceView | selectPosition() | เลือกตำแหน่งของบริษัท | ตำแหน่งถูกเพิ่มใน selectedChoices |
| 4 | CompanyChoiceView | reorderChoices() | เปลี่ยนอันดับของตัวเลือก | ลำดับใน selectedChoices เปลี่ยนตามที่เลือก |
| 5 | CompanyChoiceView | validateChoices() | เลือกครบ 5 อันดับ | คืนค่า true |
| 6 | CompanyChoiceView | saveChoices() | กดบันทึกเมื่อ validateChoices() เป็น true | ส่งข้อมูลอันดับที่เลือกไปบันทึก |
| 7 | CompanyChoiceView | - | บันทึกสำเร็จ | แสดงตัวเลือกที่บันทึกแล้ว |
