U4:T16 : ออกแบบ User Acceptance Test ตาม User Story (ระบบจับคู่บริษัท (จัดอันดับ))
-
ออกแบบ test cases สำหรับให้ผู้ใช้ทดสอบยอมรับระบบจับคู่บริษัท (จัดอันดับ) ตาม user story details และ acceptance criteria
-


User flow ที่เกี่ยวข้อง
-
ผ่านเกณฑ์ → เลือกบริษัทและจัดอันดับ → ยืนยันการเลือก


สร้าง test case ต่อ user story
-
| ลำดับ | ผู้ใช้ | สิ่งที่ผู้ใช้ทำ |
|---|---|---|
| 1 | นักศึกษา | ดูบริษัทที่เปิดรับ |
| 2 | นักศึกษา | จัดอันดับบริษัทที่สนใจ |
| 3 | นักศึกษา | กดยืนยันการเลือก |
| 4 | นักศึกษา | กดยืนยันโดยไม่เลือก / เลือกอันดับซ้ำ |
| 5 | นักศึกษา | กลับมาที่หน้าอีกครั้ง |


กำหนดเกณฑ์ผ่านที่ user ยอมรับได้
-
| ลำดับ | เกณฑ์ผ่าน |
|---|---|
| 1 | เห็นรายชื่อบริษัทครบทุกบริษัทที่เปิดรับ |
| 2 | กล่องลำดับที่เลือกแสดงบริษัทเรียงตามอันดับถูกต้อง |
| 3 | เห็นข้อความ "สำเร็จ บันทึกลำดับเรียบร้อยแล้ว" |
| 4 | เห็นข้อความแจ้งว่าต้องแก้อะไร และยังไม่บันทึก |
| 5 | อันดับที่เลือกไว้ยังอยู่ |
