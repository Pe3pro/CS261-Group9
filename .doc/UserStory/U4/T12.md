U4:T12 : ออกแบบ Unit Test Cases ส่วน DAO (ระบบจับคู่บริษัท (จัดอันดับ))
-
ออกแบบ test cases สำหรับทดสอบ DAO แต่ละตัวของระบบจับคู่บริษัท (จัดอันดับ)
-


DAO ที่ทดสอบ
-
| DAO | Method |
|---|---|
| CompanyRepository | findByStatus(), findByCompanyNameContainingIgnoreCase(), findById() |
| CompanyRankingRepository | save(), saveAll(), findByStudentIdOrderByRankNoAsc(), deleteByStudentId() |


ระบุ test cases ของแต่ละ DAO
-
| ลำดับ | DAO | Method |
|---|---|---|
| 1 | CompanyRepository | findByStatus(OPEN) |
| 2 | CompanyRepository | findById() |
| 3 | CompanyRankingRepository | saveAll() |
| 4 | CompanyRankingRepository | findByStudentIdOrderByRankNoAsc() |
| 5 | CompanyRankingRepository | save() อันดับซ้ำ |
| 6 | CompanyRankingRepository | save() บริษัทซ้ำ |
| 7 | CompanyRankingRepository | findByStudentIdOrderByRankNoAsc() ของนักศึกษาที่ยังไม่เคยจัดอันดับ |
| 8 | CompanyRepository | findByCompanyNameContainingIgnoreCase() |
| 9 | CompanyRankingRepository | deleteByStudentId() |


เขียน input / expected result
-
| ลำดับ | Input | ผลที่คาดหวัง |
|---|---|---|
| 1 | มีบริษัททั้ง OPEN และ CLOSED | คืนเฉพาะบริษัทที่เปิดรับ |
| 2 | id ที่ไม่มีอยู่ | คืน Optional.empty |
| 3 | บันทึก 5 อันดับของนักศึกษา 1 คน | ทุกแถวผูกกับนักศึกษาและบริษัทถูกต้อง |
| 4 | บันทึกอันดับสลับลำดับ (เช่น 3, 1, 5, 2, 4) | คืนเรียงอันดับ 1–5 |
| 5 | บันทึก rank_no เดียวกันซ้ำของนักศึกษาคนเดียว | ถูกปฏิเสธ (Unique `student_id`, `rank_no`) |
| 6 | บันทึกบริษัทเดียวกันซ้ำของนักศึกษาคนเดียว | ถูกปฏิเสธ (Unique `student_id`, `company_id`) |
| 7 | studentId ที่ยังไม่เคยจัดอันดับ | คืนรายการว่าง |
| 8 | ค้นหาชื่อบริษัทด้วยอักขระพิเศษ | ไม่เกิด SQL Injection |
| 9 | ลบอันดับของนักศึกษาคนหนึ่ง แล้วบันทึกอันดับเดิมซ้ำ | ลบเฉพาะของนักศึกษาคนนั้น และบันทึกใหม่ได้ |
