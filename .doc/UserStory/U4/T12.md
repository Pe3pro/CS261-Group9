U4:T12 : ออกแบบ Unit Test Cases ส่วน DAO (ระบบจับคู่บริษัท (จัดอันดับ))
-
ออกแบบ test cases สำหรับทดสอบ DAO แต่ละตัวของระบบจับคู่บริษัท (จัดอันดับ)
-


DAO ที่ทดสอบ
-
| DAO | Method |
|---|---|
| CompanyRepository | findByStatus(), findByNameContainingIgnoreCase() |
| CompanyPositionRepository | findByCompanyId(), findOpenPositions() |
| ApplicationChoiceRepository | findByApplicationIdOrderByRankAsc() |


ระบุ test cases ของแต่ละ DAO
-
| ลำดับ | DAO | Method |
|---|---|---|
| 1 | CompanyRepository | findByStatus() |
| 2 | CompanyRepository | findByNameContainingIgnoreCase() |
| 3 | CompanyPositionRepository | findByCompanyId() |
| 4 | CompanyPositionRepository | findOpenPositions() |
| 5 | ApplicationChoiceRepository | findByApplicationIdOrderByRankAsc() |


เขียน input / expected result
-
| ลำดับ | Input | ผลที่คาดหวัง |
|---|---|---|
| 1 | status | ได้รายการ Company ที่มี status ตรงกับที่ค้น |
| 2 | ชื่อบริษัท (บางส่วน) | ได้รายการ Company ที่ companyName มีคำที่ค้น |
| 3 | companyId | ได้รายการ CompanyPosition ของบริษัทนั้น |
| 4 | companyId | ได้รายการ CompanyPosition ที่เปิดรับของบริษัทนั้น |
| 5 | applicationId | ได้รายการ ApplicationChoice ของใบสมัครนั้น เรียงตาม rank จากน้อยไปมาก |
