ระบุ scenario UI เรียก API
-
| ลำดับ | การกระทำบน UI (ranking.html) | Request |
|---|---|---|
| 1 | เปิดหน้าจับคู่บริษัท | GET /api/companies |
| 2 | เปิดหน้าจับคู่บริษัท (โหลดอันดับเดิม) | GET /api/students/me/company-ranking |
| 3 | เลือกไม่ครบ 5 อันดับแล้วกด "ยืนยันการเลือก" | - (ไม่ส่ง request) |
| 4 | เลือกครบ 5 อันดับแล้วกด "ยืนยันการเลือก" | PUT /api/students/me/company-ranking |
| 5 | รีเฟรชหน้าหลังบันทึก | GET /api/students/me/company-ranking |
| 6 | นักศึกษาที่ยื่นคำร้องแล้วกด "ยืนยันการเลือก" | PUT /api/students/me/company-ranking |


เขียน input / expected result
-
| ลำดับ | Input | ผลที่คาดหวัง |
|---|---|---|
| 1 | header `X-User-Id` ของนักศึกษา | 200 ได้บริษัทที่เปิดรับ (id, name, address, status) · แสดงในรายการของช่องค้นหา |
| 2 | header `X-User-Id` ของนักศึกษา | 200 · ยังไม่เคยบันทึกได้รายการว่าง (ทุกช่องว่าง) |
| 3 | เลือก 2 อันดับ | แสดง "กรุณาเลือกบริษัทให้ครบ 5 อันดับ (เลือกแล้ว 2 อันดับ)" · Network ไม่มี PUT |
| 4 | `{"companyIds": [5 ตัว ไม่ซ้ำ]}` | 200 ได้อันดับ 1–5 · แสดง "สำเร็จ บันทึกลำดับเรียบร้อยแล้ว" |
| 5 | ผลจากข้อ 4 | 200 ได้อันดับ 1–5 ตามที่บันทึก · หน้าเว็บแสดงบริษัทในอันดับเดิม |
| 6 | บัญชีที่ยื่นคำร้องแล้ว + `companyIds` 5 ตัว | 409 `RANKING_LOCKED` · แสดง "คุณยื่นคำร้องแล้ว ไม่สามารถแก้ไขอันดับบริษัทได้" และแก้ไขไม่ได้ |
