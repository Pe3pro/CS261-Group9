ระบุ scenario UI เรียก API
-
| ลำดับ | การกระทำบน UI (ranking.html) | Request |
|---|---|---|
| 1 | เปิดหน้าจับคู่บริษัท | GET /api/companies |
| 2 | เลือกบริษัทเพื่อดูตำแหน่ง | GET /api/companies/{id}/positions |
| 3 | กรอกใบสมัคร | POST /api/applications |
| 4 | กดปุ่ม "ยืนยันการเลือก" เมื่อจัดอันดับถูกต้อง | PUT /api/applications/{id}/choices |
| 5 | แสดงลำดับที่บันทึกแล้ว | - |


เขียน input / expected result
-
| ลำดับ | Input | ผลที่คาดหวัง |
|---|---|---|
| 1 | - | ได้รายชื่อบริษัทที่เปิดรับ (id, name, status) และแสดงในกล่อง "รายชื่อบริษัท" |
| 2 | id ของบริษัท | ได้ตำแหน่งที่เปิดรับ (id, positionName, quota, availableSlots) |
| 3 | studentId, formId, answers | 201 Created ได้ Application ID |
| 4 | id ของใบสมัคร + อันดับที่เลือก | 200 OK และแสดง "สำเร็จ บันทึกลำดับเรียบร้อยแล้ว" |
| 5 | ผลจากข้อ 4 | กล่อง "ลำดับที่เลือก" แสดงอันดับที่บันทึก |
