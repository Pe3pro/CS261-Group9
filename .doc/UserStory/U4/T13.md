U4:T13 : ออกแบบ Integration Test ระหว่าง UI กับ API (ระบบจับคู่บริษัท (จัดอันดับ))
-
ออกแบบ scenario ทดสอบการเรียกใช้ API จากหน้า UI ของระบบจับคู่บริษัท (จัดอันดับ)
-

Sequence Diagram
-
![Sequence Diagram](<U4-10 Sequence diagram.png>)


ระบุ scenario UI เรียก API
-
| ลำดับ | การกระทำบน UI | Request |
|---|---|---|
| IT-UA-01 | นักศึกษาดูบริษัทที่เปิดรับ | GET /api/companies |
| IT-UA-02 | เลือกบริษัทและดูตำแหน่ง | GET /api/companies/{id}/positions |
| IT-UA-03 | กรอกใบสมัคร | POST /api/applications |
| IT-UA-04 | เลือกบริษัท 5 อันดับ | PUT /api/applications/{id}/choices |
| IT-UA-05 | แสดงตัวเลือกที่บันทึกแล้ว | - |


เขียน input / expected result
-
| ลำดับ | Input | ผลที่คาดหวัง |
|---|---|---|
| IT-UA-01 | - | ได้ Company List (id, name, status) และหน้าเว็บแสดงบริษัท |
| IT-UA-02 | id ของบริษัทที่เลือก | ได้ Position List (id, positionName, quota, availableSlots) และหน้าเว็บแสดงตำแหน่ง |
| IT-UA-03 | studentId, formId, answers | 201 Created ได้ Application ID |
| IT-UA-04 | id ของใบสมัคร + ตัวเลือกอันดับ 1-5 | 200 OK |
| IT-UA-05 | ผลจาก IT-UA-04 | หน้าเว็บแสดงอันดับที่เลือก |
