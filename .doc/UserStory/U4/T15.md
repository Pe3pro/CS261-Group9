สร้าง test case ต่อ Sequence Diagram แต่ละอัน
-
| ลำดับ | ขั้นตอนใน Sequence Diagram | Frontend → API | API → Service → Database |
|---|---|---|---|
| 1 | นักศึกษาเปิดหน้าจับคู่บริษัท | GET /api/companies | ดึงบริษัทที่เปิดรับจาก `companies` |
| 2 | โหลดอันดับที่เคยบันทึก | GET /api/students/me/company-ranking | ดึงอันดับจาก `company_rankings` เรียง 1–5 |
| 3 | ค้นหาและเลือกบริษัทลงอันดับ 1–5 | - | - |
| 4 | กดยืนยันตอนเลือกครบ 5 อันดับ | PUT /api/students/me/company-ranking | ตรวจเงื่อนไข → ลบชุดเดิม → บันทึก 5 แถวลง `company_rankings` |
| 5 | เปิดหน้าใหม่หลังบันทึก | GET /api/students/me/company-ranking | ดึงอันดับที่บันทึกจาก `company_rankings` |


เขียน input / expected result
-
| ลำดับ | Input | ผลที่คาดหวัง |
|---|---|---|
| 1 | login ด้วยนักศึกษาที่ผ่าน U2 และยังไม่ยื่นคำร้อง | หน้าเว็บแสดงบริษัทที่เปิดรับในช่องค้นหา (ไม่มีบริษัท CLOSED) |
| 2 | - | ยังไม่เคยบันทึก: ทุกอันดับว่าง |

| 4 | กด "ยืนยันการเลือก" | 200 OK · แสดง "สำเร็จ บันทึกลำดับเรียบร้อยแล้ว" · `company_rankings` มี 5 แถวของนักศึกษา |
| 5 | รีเฟรชหน้า / login ใหม่ | หน้าเว็บแสดงบริษัทในอันดับ 1–5 ตามที่บันทึก |
