U4:T15 : ออกแบบ System Test ตาม Sequence Diagram (ระบบจับคู่บริษัท (จัดอันดับ))
-
ออกแบบ test cases ทดสอบทั้งระบบของระบบจับคู่บริษัท (จัดอันดับ) ตาม Sequence Diagram แต่ละอัน
-


Sequence Diagram
-
![Sequence Diagram](<U4-10 Sequence diagram.png>)


สร้าง test case ต่อ Sequence Diagram แต่ละอัน
-
| ลำดับ | ขั้นตอนใน Sequence Diagram | Frontend → API | API → Service → Database |
|---|---|---|---|
| 1 | นักศึกษาดูบริษัทที่เปิดรับ | GET /api/companies | ค้นหาบริษัท → ดึงบริษัทที่เปิดรับ |
| 2 | เลือกบริษัทและดูตำแหน่ง | GET /api/companies/{id}/positions | ค้นหาตำแหน่ง → ดึงตำแหน่งที่เปิดรับ |
| 3 | กรอกใบสมัคร | POST /api/applications | สร้างใบสมัคร → บันทึกใบสมัคร |
| 4 | เลือกบริษัทและจัดอันดับ | PUT /api/applications/{id}/choices | ตรวจสอบและบันทึกตัวเลือก → บันทึกอันดับ |
| 5 | แสดงตัวเลือกที่บันทึกแล้ว | - | - |


เขียน input / expected result
-
| ลำดับ | Input | ผลที่คาดหวัง |
|---|---|---|
| 1 | - | ได้รายชื่อบริษัท (Company List) และหน้าเว็บแสดงบริษัท |
| 2 | id ของบริษัท | ได้ Position List และหน้าเว็บแสดงตำแหน่ง |
| 3 | ข้อมูลใบสมัคร | ได้ Application ID และ 201 Created |
| 4 | id ของใบสมัคร + อันดับที่เลือก | บันทึกสำเร็จ → Success → 200 OK |
| 5 | ผลจากข้อ 4 | หน้าเว็บแสดงตัวเลือกที่บันทึกแล้ว |
