เขียน API และ DTO
-
Method	Endpoint	หน้าที่	ผลลัพธ์ (DTO)
GET	/api/companies	ดูบริษัทที่เปิดรับ	CompanyResponse[]
GET	/api/companies/{id}/positions	ดูตำแหน่งที่เปิดรับและยังว่าง	PositionResponse[]
PUT	/api/applications/{id}/choices	บันทึกบริษัท 1–5 อันดับ  ApplicationChoicesResponse
GET /api/notifications	แจ้งเตือน   NotificationResponse 


| Method |  Endpoint   |    หน้าที่    |   ผลลัพธ์ (DTO) |

|  GET   | /api/companies                | ดูบริษัทที่เปิดรับ            | CompanyResponse[]|

|  GET   | /api/companies/{id}/positions | ดูตำแหน่งที่เปิดรับและยังว่าง   |PositionResponse[]|

|  PUT   | api/applications/{id}/choices | บันทึกบริษัท 1–5 อันดับ     | ApplicationChoicesResponse|


DTO class
-
| Class | Attributes | หน้าที่ |
|---|---|---|
| CompanyResponse | id: Long<br>name: String<br>status: CompanyStatus | ส่งข้อมูลบริษัท |
| PositionResponse | id: Long<br>positionName: String<br>quota: Integer<br>availableSlots: Integer | ส่งตำแหน่งงานและจำนวนรับ |
| ApplicationResponse | id: Long<br>status: ApplicationStatus<br>submittedAt: LocalDateTime | ส่งข้อมูลใบสมัคร  |
