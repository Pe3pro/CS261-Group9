U4:T8 : Develop API_DTO  + Unit Test API
-

เขียน API และ DTO
-
Endpoint ตามเอกสาร Unit Test ระบบสหกิจศึกษา (หัวข้อ U4) · ทุก request ส่ง header `X-User-Id` เพื่อบอกว่าเป็นผู้ใช้คนไหน

| Method | Endpoint | หน้าที่ | Request (DTO) | Response (DTO) |
|---|---|---|---|---|
| GET | /api/companies | ดูบริษัทที่เปิดรับ | - | CompanyResponse[] |
| GET | /api/students/me/company-ranking | ดูอันดับบริษัทที่บันทึกไว้ (เรียง 1–5) | - | RankingItemResponse[] |
| PUT | /api/students/me/company-ranking | บันทึกบริษัท 5 อันดับ (แทนที่ชุดเดิม) | RankingRequest | RankingItemResponse[] |
| PUT | /api/staff/companies/{id} | เจ้าหน้าที่เปิด–ปิดรับบริษัท | CompanyStatusRequest | CompanyResponse |

Error ที่ API ตอบกลับ (รูปแบบ `{"code": "...", "message": "..."}`)

| Status | code | เมื่อไร |
|---|---|---|
| 400 | INVALID_RANKING | เลือกไม่ครบ 5 อันดับ หรือมีอันดับที่เว้นว่าง |
| 400 | DUPLICATE_COMPANY | เลือกบริษัทเดียวกันซ้ำ |
| 400 | COMPANY_NOT_FOUND | มี company id ที่ไม่มีอยู่ |
| 400 | COMPANY_CLOSED | มีบริษัทที่ปิดรับแล้ว (บอกชื่อบริษัท) |
| 401 | UNAUTHORIZED | ไม่ได้ส่ง X-User-Id หรือไม่มีผู้ใช้นี้ |
| 403 | NOT_ELIGIBLE | ยังไม่ผ่านการตรวจคุณสมบัติ (U2) |
| 403 | FORBIDDEN | ผู้ใช้บทบาทอื่นเรียก API ที่ไม่ใช่ของตัวเอง เช่น นักศึกษาเรียก /api/staff/... |
| 409 | RANKING_LOCKED | ยื่นคำร้อง (U3) ไปแล้ว แก้อันดับไม่ได้ |

DTO class
-
| Class | Attributes | หน้าที่ |
|---|---|---|
| CompanyResponse | id: Long<br>name: String<br>address: String<br>status: CompanyStatus | ส่งข้อมูลบริษัท |
| RankingRequest | companyIds: List&lt;Long&gt; | รับ id บริษัท 5 ตัว ตัวแรก = อันดับ 1 |
| RankingItemResponse | rank: Integer<br>companyId: Long<br>companyName: String | ส่งบริษัทหนึ่งรายการในลำดับ |
| CompanyStatusRequest | status: CompanyStatus (OPEN / CLOSED) | รับสถานะบริษัทจากเจ้าหน้าที่ |

วิธีรัน
1. เปิดระบบ `docker compose up -d --build` (ข้อมูลตัวอย่างบริษัทและนักศึกษามาจาก `RankingDemoSeeder`)
2. Postman → Import → เลือกไฟล์ collection
3. คลิกขวาที่ collection → Run collection → Run (ต้องรันตามลำดับ เพราะโฟลเดอร์ 00 หา userId ให้ก่อน)
