ขั้นตอนการรัน
-
1. `docker compose down -v` แล้ว `docker compose up -d --build`
2. เปิด http://localhost:8081/login.html แล้ว login ด้วยบัญชีนักศึกษา
3. ไปที่หน้าจับคู่บริษัท (`ranking.html`)
4. เปิด DevTools แท็บ Network ติ๊ก Keep log แล้วรีเฟรชหน้า
5. ทำตาม Input ของแต่ละ test case แล้วดู request ในแท็บ Network และผลบนหน้าจอ
