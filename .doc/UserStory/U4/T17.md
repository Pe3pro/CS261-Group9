2. เปิด http://localhost:8081/login.html แล้ว login ด้วยบัญชีนักศึกษา ผ่านการตรวจสอบคุณสมบัติ (ยังไม่ยื่นคำร้อง)

4. เปิด DevTools แท็บ Network เลือก Fetch/XHR ติ๊ก Keep log แล้วรีเฟรชหน้า
5. ทำตาม Input ของแต่ละ test case แล้วดู request ในแท็บ Network และผลบนหน้าจอ
