เขียน Entity class
-
| Entity | Attributes | Methods |
|---|---|---|
| Company | id: Long<br>companyName: String<br>address: String<br>contactPerson: String<br>email: String<br>phone: String<br>status: CompanyStatus | openRecruitment(): void<br>closeRecruitment(): void<br>updateContactInfo(): void |
| CompanyRanking | id: Long<br>studentId: Long<br>companyId: Long<br>rankNo: Integer<br>createdAt: LocalDateTime | - |
| CompanyPosition | id: Long<br>companyId: Long<br>positionName: String<br>description: String<br>quota: Integer<br>availableSlots: Integer<br>status: PositionStatus | isOpen(): Boolean<br>hasAvailableSlot(): Boolean<br>updateQuota(quota): void |
