เช็กให้ตรงกับ Sequence Diagram
-
| ลำดับ | ขั้นตอนใน Sequence Diagram | Request | ผลที่คาดหวัง | ผล |
|---|---|---|---|---|
| 1 | นักศึกษาดูบริษัทที่เปิดรับ | GET /api/companies | แสดงบริษัท (Company List) | ⚠️ API ตอบ 200 ได้ 6 บริษัทที่เปิดรับ แต่หน้า ranking ไม่เรียก API แสดงบริษัท A–D ที่เขียนไว้ในหน้า |
| 2 | เลือกบริษัทและดูตำแหน่ง | GET /api/companies/{id}/positions | แสดงตำแหน่ง (Position List) | ❌ API ตอบ 404 และหน้าเว็บไม่มีส่วนแสดงตำแหน่ง |
| 3 | เลือกบริษัทและจัดอันดับ | PUT /api/applications/{id}/choices | ตรวจสอบและบันทึกอันดับ | ❌ path นี้ตอบ 404 · API ที่เขียนจริงคือ `PUT /api/students/me/company-ranking` (ผ่าน Postman 35/35 ใน T8) แต่หน้าเว็บยังไม่เรียก |
| 4 | แสดงตัวเลือกที่บันทึกแล้ว | - | หน้าเว็บแสดงอันดับที่เลือก | ⚠️ หน้าเว็บแสดงอันดับได้ แต่เป็นข้อมูลในเบราว์เซอร์ ไม่ได้มาจากฐานข้อมูล |

สรุป: UI, API และ DAO ทำงานได้แยกกัน (unit test ผ่านทั้งหมดใน T7–T9) แต่หน้า ranking ยังไม่เรียก API จึงยังไม่ทำงานต่อกันตาม Sequence Diagram · รายละเอียดดู [T17.md](T17.md), [T19.md](T19.md)
