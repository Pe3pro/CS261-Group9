รวมโค้ดทุก component ของระบบสร้างและยื่นคำร้องออนไลน์ (นศ.) (UI, API, DAO) ให้ทำงานต่อกันตามลำดับใน Sequence Diagram แล้ว push ขึ้น Git

Sequence Diagram
-
![Sequence Diagram](<U4-10 Sequence diagram.png>)


เช็กให้ตรงกับ Sequence Diagram
-
| ลำดับ | ขั้นตอนใน Sequence Diagram | Request | ผลที่คาดหวัง | ผล |
|---|---|---|---|---|
| 1 | นักศึกษาอัปโหลดไฟล์ PDF [ไฟล์ถูกต้อง] | POST /api/documents | ตรวจชนิดไฟล์และขนาด → จัดเก็บไฟล์ PDF (File Reference) → บันทึกข้อมูลเอกสาร → ได้ Document ID → 201 Created → แสดงอัปโหลดสำเร็จ | |
| 2 | นักศึกษาอัปโหลดไฟล์ PDF [ไฟล์ไม่ถูกต้อง] | POST /api/documents | File Error → 400 Bad Request → แจ้งให้อัปโหลด PDF ใหม่ | |
| 3 | กดส่งใบสมัคร [ข้อมูลครบถ้วน] | POST /api/applications/{id}/submit | ตรวจใบสมัคร ตัวเลือก และเอกสาร → เปลี่ยนสถานะเป็น SUBMITTED → Submission Success → 200 OK → แสดงยื่นใบสมัครสำเร็จ | |
| 4 | กดส่งใบสมัคร [ข้อมูลไม่ครบ] | POST /api/applications/{id}/submit | Validation Errors → 400 Bad Request → แจ้งข้อมูลที่ต้องแก้ไข | |
