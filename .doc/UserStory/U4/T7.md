U4:T7 : พัฒนาหน้า UI + Unit Test UI (ระบบจับคู่บริษัท (จัดอันดับ))
-
พัฒนาหน้าจอของระบบจับคู่บริษัท (จัดอันดับ) ตาม UI Prototype ที่ออกแบบไว้ และทำ unit test ส่วน UI
-


เขียนหน้า UI ตาม prototype
-
![prototype](<U4 Ranking.png>)

หน้าที่พัฒนา: `frontend/ranking.html` · `initRanking()` ใน `frontend/js/script.js`


เขียน unit test ส่วน UI
-
ไฟล์ทดสอบ `frontend/tests/u4.test.js` (Vitest + jsdom) จำลองหน้า ranking.html แล้วตรวจการแสดงผลและการตอบสนองของหน้าเว็บ · test cases อ้างอิง [T11.md](T11.md)

วิธีรัน (ไม่ต้องติดตั้ง Node.js ในเครื่อง ใช้ Node.js ใน Docker)

```powershell
docker run --rm -v "${PWD}:/app" -w /app node:20 sh -c "npm install && npm run test:ui -- frontend/tests/u4.test.js"
```
