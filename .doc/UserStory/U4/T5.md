U4:T5 : ออกแบบ UI Prototype, DTO และ API (ระบบจับคู่บริษัท (จัดอันดับ))
-
ออกแบบหน้าจอ (UI Prototype) ของระบบจับคู่บริษัท (จัดอันดับ) ให้พร้อมนำไปพัฒนาจริง พร้อมกำหนด API Spec และโครงสร้าง DTO ที่ใช้รับ-ส่งข้อมูลระหว่าง UI กับ API
-

ทำ UI prototype
-
![U4 Ranking (new)](<U4 Ranking(new).png>)

| ส่วนของหน้า | หน้าที่ |
|---|---|
| ช่องอันดับ 1–5 | คลิกแล้วพิมพ์ค้นหาบริษัทจากชื่อ แสดงรายชื่อบริษัทที่เปิดรับให้เลือก |
| รายการบริษัทที่ค้นเจอ | ไม่แสดงบริษัทที่เลือกในอันดับอื่นแล้ว และบอกว่าซ่อนบริษัทไหนไว้ |
| ปุ่ม "ล้าง ✕" ในแต่ละอันดับ | ล้างบริษัทของอันดับนั้น |
| ปุ่ม "ยืนยันการเลือก" | บันทึกอันดับ (ต้องเลือกครบ 5 อันดับ) |
| ปุ่ม "ล้างทั้งหมด" | ล้างทุกอันดับ |
| "เลือกแล้ว X จาก 5 อันดับ" | บอกจำนวนอันดับที่เลือกแล้ว |

เขียน API Spec
-
| Method | Endpoint | หน้าที่ |
|---|---|---|
| GET | /api/companies | ดูบริษัทที่เปิดรับ |
| GET | /api/students/me/company-ranking | ดูอันดับที่บันทึกไว้ |
| PUT | /api/students/me/company-ranking | บันทึกบริษัท 5 อันดับ |
