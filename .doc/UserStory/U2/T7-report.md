# U2:T7 UI Unit Test Report

## 1. วัตถุประสงค์

ทดสอบการทำงานของหน้า UI สำหรับระบบตรวจสอบคุณสมบัติอัตโนมัติ เพื่อยืนยันว่าหน้าเว็บสามารถตรวจสอบข้อมูลที่ผู้ใช้กรอก ควบคุมสถานะปุ่ม ส่งข้อมูลไปยัง API และแสดงผลการตรวจสอบได้อย่างถูกต้อง

นอกจากนี้ยังทดสอบการจัดการข้อผิดพลาดในกรณีที่ API ตอบกลับด้วย HTTP Status ที่ไม่รองรับ ส่งข้อมูลกลับมาในรูปแบบที่ไม่ถูกต้อง หรือไม่สามารถเชื่อมต่อ Backend ได้

## 2. ขอบเขตการทดสอบ

ส่วนที่ทดสอบประกอบด้วย:

- การเปิดและปิดปุ่มตรวจสอบคุณสมบัติ
- การตรวจสอบการยืนยันเงื่อนไขทั้ง 3 ข้อ
- การตรวจสอบค่า GPA ตามเกณฑ์
- การตรวจสอบข้อมูลที่กรอกไม่ครบ
- การตรวจสอบ GPA ที่กรอกผิดรูปแบบ
- การสร้าง Request และส่งข้อมูลไปยัง API
- การแสดงผลผ่านคุณสมบัติ
- การแสดงผลไม่ผ่านคุณสมบัติพร้อมเหตุผล
- การจัดการ HTTP Status ที่ไม่รองรับ
- การจัดการข้อมูลตอบกลับที่มีรูปแบบไม่ถูกต้อง
- การจัดการกรณีที่ไม่สามารถเชื่อมต่อ API ได้

## 6. รายละเอียดการทดสอบ

### 6.1 การควบคุมปุ่มตรวจสอบ

เมื่อผู้ใช้ยังยืนยันเงื่อนไขไม่ครบทั้ง 3 ข้อ ปุ่มตรวจสอบคุณสมบัติต้องถูกปิดไว้ เพื่อป้องกันไม่ให้ส่งข้อมูลที่ยังไม่สมบูรณ์ไปยัง API

เมื่อผู้ใช้ยืนยันครบทั้ง 3 ข้อ ปุ่มตรวจสอบจึงเปิดใช้งานและสามารถกดตรวจสอบได้

### 6.2 กรณีผ่านคุณสมบัติ

กำหนด GPA เป็น `2.75` พร้อมข้อมูลอื่นที่ผ่านเงื่อนไข ระบบต้องส่ง Request ไปยัง:

```text
http://localhost:8080/api/eligibility/check
```

โดยใช้ Method:

```text
POST
```

เมื่อ API ตอบกลับว่า `eligible = true` หน้า UI ต้องแสดงข้อความ `ผ่านคุณสมบัติ`

### 6.3 กรณีไม่ผ่านคุณสมบัติ

กำหนด GPA เป็น `2.74` ซึ่งต่ำกว่าเกณฑ์ `2.75` เมื่อ API ตอบกลับว่า `eligible = false` หน้า UI ต้องแสดงข้อความ `ไม่ผ่านคุณสมบัติ` พร้อมเหตุผล:

```text
GPA ต้องไม่ต่ำกว่า 2.75
```

### 6.4 กรณีกรอกข้อมูลไม่ครบ

เมื่อผู้ใช้ไม่กรอกรหัสนักศึกษาหรือเว้นข้อมูลที่จำเป็น หน้า UI ต้องแสดงข้อความให้กรอกข้อมูลให้ครบถ้วน และต้องไม่เรียก API

### 6.5 กรณีกรอก GPA ผิดรูปแบบ

เมื่อผู้ใช้กรอก GPA เป็นค่าที่ไม่ใช่ตัวเลข เช่น:

```text
3.10abc
```

หน้า UI ต้องแสดงข้อความแจ้งว่ารูปแบบ GPA ไม่ถูกต้อง และต้องไม่ส่ง Request ไปยัง API

### 6.6 การจัดการข้อผิดพลาดจาก API

หน้า UI ต้องจัดการข้อผิดพลาดต่อไปนี้ได้:

- API ตอบกลับด้วย HTTP Status ที่ไม่ใช่ `200` หรือ `400`
- API ส่งข้อมูล JSON ที่ไม่ตรงกับโครงสร้าง `EligibilityResponse`
- เกิด Network Error หรือไม่สามารถเชื่อมต่อ Backend ได้

ในทุกกรณี ระบบต้องไม่แสดงว่าผู้ใช้ผ่านคุณสมบัติ และต้องแสดงข้อความผิดพลาดที่ผู้ใช้สามารถเข้าใจได้
