# U2:T19 System Test Report

## 1. วัตถุประสงค์

ทดสอบการทำงานของระบบตรวจสอบคุณสมบัติอัตโนมัติแบบ System Test ตั้งแต่นักศึกษาเข้าสู่ระบบ กรอกข้อมูลผ่าน UI ส่งข้อมูลไปยัง REST API ประมวลผลผ่าน Service ตรวจสอบข้อมูลนักศึกษาจากฐานข้อมูล และบันทึกผลผ่าน DAO ลงใน MySQL

การทดสอบรอบนี้แก้ไขจากการทดสอบเดิมที่ใช้รหัสนักศึกษาซึ่งไม่มีอยู่ในข้อมูลตัวอย่างของระบบ โดยเปลี่ยนมาใช้บัญชี `6609650001` ซึ่งมีข้อมูลอยู่จริงในตาราง `students`

## 4. ระบบที่เกี่ยวข้อง

ลำดับการทำงานที่ทดสอบประกอบด้วย:

1. นักศึกษา Login ด้วยบัญชี `6609650001`
2. Frontend โหลดข้อมูลนักศึกษาจากฐานข้อมูล
3. Frontend ส่ง `X-User-Id: 3` ไปยัง API
4. API ตรวจสอบผู้ใช้และค้นหาข้อมูลในตาราง `students`
5. Service ตรวจ Student ID, GPA, หลักสูตร เกรด สถานะรายวิชา และการยืนยัน
6. Service ประเมินผลผ่านหรือไม่ผ่านคุณสมบัติ
7. กรณีข้อมูลถูกต้อง ระบบบันทึกผลลง `eligibility_records`
8. กรณีข้อมูลไม่ถูกต้อง ระบบไม่บันทึกผล
9. Frontend แสดงผลตอบกลับให้ผู้ใช้งาน
