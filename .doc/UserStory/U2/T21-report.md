# U2:T21 Demo ระบบตรวจสอบคุณสมบัติอัตโนมัติ

## 1. วัตถุประสงค์

สาธิตการใช้งานระบบตรวจสอบคุณสมบัติอัตโนมัติให้ผู้ใช้งานทดลองใช้ และรวบรวมความคิดเห็นเพื่อนำไปปรับปรุงระบบใน Sprint ถัดไป

## 2. ส่วนที่นำเสนอ

- การกรอกข้อมูลนักศึกษา
- การเลือกหลักสูตร 61 หรือ 66
- การกรอก GPA เกรด และสถานะรายวิชา
- การยืนยันเงื่อนไขทั้ง 3 ข้อ
- การแสดงผลผ่านหรือไม่ผ่านคุณสมบัติ
- การแสดงเหตุผลและคำเตือน

## 3. กรณีที่ใช้ Demo

| กรณี | ผลที่คาดหวัง | ผลการ Demo |
|---|---|---|
| ข้อมูลครบและผ่านเกณฑ์ | แสดงข้อความผ่านคุณสมบัติและคำเตือน | ผ่าน |
| GPA ต่ำกว่า 2.75 | แสดงข้อความไม่ผ่านและเหตุผลเกี่ยวกับ GPA | ผ่าน |

## 4. ผลการ Demo

ระบบสามารถรับข้อมูลจากผู้ใช้ ส่งไปตรวจสอบผ่าน API และแสดงผลการตรวจสอบบนหน้า UI ได้อย่างถูกต้อง

กรณีผ่านเกณฑ์ ระบบแสดงข้อความ `ผ่านคุณสมบัติ` พร้อมคำเตือนตามหลักสูตร

กรณี GPA ต่ำกว่าเกณฑ์ ระบบแสดงข้อความ `ไม่ผ่านคุณสมบัติ` พร้อมเหตุผลว่า GPA ต้องไม่ต่ำกว่า 2.75
