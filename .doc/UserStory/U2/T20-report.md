# U2:T20 User Acceptance Test Report

## 1. วัตถุประสงค์

ทดสอบการยอมรับระบบตรวจสอบคุณสมบัติอัตโนมัติจากมุมมองของนักศึกษา เพื่อยืนยันว่าระบบทำงานตรงตาม User Story U2 และ Acceptance Criteria ที่กำหนดไว้ใน U2:T16

## 2. ข้อมูลการทดสอบ

- User Story: U2 ตรวจสอบคุณสมบัติอัตโนมัติ
- วันที่ทดสอบ: 18–19 ตุลาคม 2569
- ผู้ทดสอบ: นักศึกษาผู้ใช้งานระบบ
- Frontend: Vite บน `http://127.0.0.1:5500`
- Backend: Spring Boot บน `http://127.0.0.1:8080`
- Database: MySQL 8.4 ผ่าน Docker

## 5. ความคิดเห็นจากผู้ทดสอบ

- หน้าจอกรอกข้อมูลและผลการตรวจสอบสามารถเข้าใจได้
- ระบบแสดงผลผ่านหรือไม่ผ่านอย่างชัดเจน
- เหตุผลที่ทำให้ไม่ผ่านระบุ GPA ชื่อวิชา และสถานะรายวิชาได้ชัดเจน
- คำเตือนเปลี่ยนตามหลักสูตร 61 และ 66 ได้ถูกต้อง
- ระบบป้องกันการตรวจสอบเมื่อยืนยันเงื่อนไขไม่ครบ
- ข้อความแจ้งข้อมูลไม่ครบและข้อมูลผิดรูปแบบช่วยให้ผู้ใช้กลับไปแก้ไขได้

## 6. ข้อเสนอแนะ

- ควรเพิ่มเครื่องหมายหรือสีเน้นบริเวณช่องข้อมูลที่กรอกผิด เพื่อให้ผู้ใช้ค้นหาช่องที่ต้องแก้ไขได้เร็วขึ้น
- ควรแสดงข้อความใกล้ปุ่มตรวจสอบเมื่อผู้ใช้ยังยืนยันเงื่อนไขไม่ครบ
- ควรเพิ่มหน้าประวัติผลการตรวจสอบ เพื่อให้นักศึกษาย้อนกลับมาดูผลเดิมได้

## 7. สรุปผล

ทดสอบ User Acceptance Test จำนวน 8 กรณี และผ่านทั้งหมด 8 กรณี

ระบบสามารถตรวจสอบคุณสมบัติของนักศึกษาหลักสูตร 61 และ 66 แสดงผลผ่านหรือไม่ผ่าน แสดงเหตุผลและคำเตือน รวมถึงตรวจพบข้อมูลไม่ครบ ข้อมูลผิดรูปแบบ และการยืนยันเงื่อนไขไม่ครบได้ตาม Acceptance Criteria

ดังนั้น ผู้ทดสอบยอมรับการทำงานของ User Story U2 สำหรับขอบเขตที่กำหนด
