# U2:T11 Design Unit Test Cases ส่วน UI

## 1. วัตถุประสงค์

ออกแบบ Unit Test Cases สำหรับตรวจสอบการทำงานของส่วนติดต่อผู้ใช้ โดยครอบคลุมหน้า UI ทั้งหมดของระบบ พร้อมระบุ Input และ Expected Result ของแต่ละกรณี

## 2. ขอบเขตการทดสอบ

หน้า UI ที่นำมาออกแบบ Test Case มีดังนี้:

1. `login.html` หน้าเข้าสู่ระบบ
2. `index.html` หน้ากรอกข้อมูลนักศึกษา
3. `check.html` หน้าตรวจสอบคุณสมบัติ
4. `ranking.html` หน้าจัดอันดับบริษัท
5. `submit.html` หน้ายืนยันและส่งคำร้อง

---

## 8. สรุป

ออกแบบ Unit Test Cases สำหรับ UI ครบทั้ง 5 หน้า โดยครอบคลุมกรณีข้อมูลถูกต้อง ข้อมูลไม่ครบ ข้อมูลผิดรูปแบบ ผลผ่านคุณสมบัติ ผลไม่ผ่านคุณสมบัติ และการเลือกข้อมูลที่ไม่ถูกต้อง
