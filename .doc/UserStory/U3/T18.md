ขั้นตอนการรัน
-

2. รันคำสั่ง cd demo แล้ว mvnw.cmd test -Dtest=ApplicationApiDaoIT
3. ผลดิบอยู่ที่ demo/target/surefire-reports/
4. ถ้าใช้ Postman ให้ import ไฟล์ Collection แล้วกด Run collection แล้วตรวจฐานข้อมูลหลังแต่ละ request
