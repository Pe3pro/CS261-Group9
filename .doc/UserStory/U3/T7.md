สิ่งที่เปลี่ยนจากต้นแบบ (ต่อหน้าเว็บเข้ากับ API จริง)
-
- หน้า submit.html เดิมตรวจแค่ว่ามีไฟล์แนบ ตอนนี้ js/script.js (initSubmit) เรียก API จริงตามลำดับ
  GET /api/students/me → GET /api/forms/published → GET /api/requests/me → POST /api/requests → PUT /api/requests/{id}/form → POST /api/requests/{id}/documents → POST /api/requests/{id}/submit
- ตรวจฝั่งหน้าเว็บก่อนส่ง: ช่องบังคับ (ตัดช่องว่าง), รูปแบบอีเมล, รูปแบบเบอร์โทร, ไฟล์ต้องเป็น .pdf และไม่เกิน 10 MB
- ยืนยันก่อนส่ง (window.confirm) · ปุ่มถูกปิดระหว่างรอ กันกดซ้ำ
- รหัส คณะ สาขา เกรดเฉลี่ย ดึงจากฐานข้อมูล (GET /api/students/me) และแก้ไขไม่ได้
- แจ้งตั้งแต่เปิดหน้า ถ้ามีคำร้องค้างอยู่ (ยื่นซ้ำ) หรือแบบฟอร์มหมดเขตแล้วตามเวลา server
- คำร้องที่ถูกส่งกลับ (NEED_CORRECTION) แสดงเหตุผลจากเจ้าหน้าที่ เติมข้อมูลเดิม และส่งใหม่ด้วยเลขที่เดิม
- server ไม่ทำงาน แจ้ง "ไม่สามารถเชื่อมต่อระบบได้" ข้อมูลที่กรอกไม่หาย · ร่างที่กรอกไว้เก็บใน sessionStorage
- เพิ่ม div#s_note ใน submit.html สำหรับข้อความแจ้งตั้งแต่เปิดหน้า และจำกัด accept=".pdf,application/pdf"
