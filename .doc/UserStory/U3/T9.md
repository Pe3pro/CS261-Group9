สิ่งที่เพิ่มใน T9
-
- Application: เพิ่ม Foreign Key applications.student_id → students.id (fk_applications_student) ตาม ER diagram และ method markUpdated()
- ApplicationStatus: เพิ่ม canMoveTo(), isEditableByStudent(), blocksNewRequest() ใช้คุมเส้นทางสถานะ
- ApplicationRepository.findByStudentIdOrderByIdDesc, FormResponseRepository.findByApplicationIdAndFormFieldId
- เพราะมี Foreign Key แล้ว จึงแก้ข้อมูลตั้งต้นใน ApplicationReviewRepositoryTest (ของ U5) ให้สร้างนักศึกษาก่อนบันทึกคำร้อง (test ของ U5 ยังผ่านครบ 7 ข้อ)
- ชื่อในเอกสาร → ชื่อในโค้ด: RequestRepository = ApplicationRepository, FormAnswerRepository = FormResponseRepository

- ปัญหาที่พบและการแก้ไข:
  - เดิมตาราง applications ไม่มี Foreign Key ไป students ทำให้ U3-DAO-05 ไม่ผ่าน → เพิ่ม @ManyToOne (insertable=false, updatable=false) ใน Application เพื่อสร้าง Foreign Key แล้วรันซ้ำผ่าน
  - U3-DAO-08: ApplicationRepository ค้นด้วย id ชนิด Long ใส่ข้อความไม่ได้อยู่แล้ว จึงทดสอบด้วย query ที่รับ String (StudentRepository.findByStudentId) แล้วตรวจว่าตาราง applications ยังอยู่ครบ
