ค่าของ enum

- FormStatus: DRAFT, PUBLISHED, ARCHIVED
- DocumentStatus: UPLOADED, VERIFIED, REJECTED

DAO
-
![.doc/UserStory/U3/U3-T6 DAO_Class_Diagram.png](<U3-T6 DAO_Class_Diagram.png>)

| DAO | Method | ใช้ทำอะไรใน U3 |
|---|---|---|
| ApplicationRepository | save, findById | บันทึกและค้นคำร้อง |
| | findByStudentId | ดูว่านักศึกษามีคำร้องค้างอยู่ไหม (ใช้ตรวจยื่นซ้ำ) |
| | findByStatus | ค้นคำร้องตามสถานะ |
| FormTemplateRepository | findById | อ่านวันหมดเขตของฟอร์ม (ใช้ตรวจหมดเขต) |
| | findByStatus, findByVersion | ค้นฟอร์มที่เปิดใช้งาน |
| FormResponseRepository | save, findByApplicationId | บันทึกและอ่านคำตอบในฟอร์ม |
| DocumentRepository | save, findByApplicationId, findById | บันทึกและอ่านไฟล์ Transcript |
| StudentRepository | findByStudentId, findByUserId | ดึงข้อมูลนักศึกษามาเติมในหน้ายื่นคำร้อง |

ทุก DAO อยู่ที่ demo/src/main/java/com/example/demo/dao/ และ extends JpaRepository<Entity, Long>

Unit test DAO
-
- วิธีทดสอบ: @DataJpaTest กับฐานข้อมูล H2 ในหน่วยความจำ ทุก test ล้างข้อมูลคืนอัตโนมัติ
- ไฟล์ test: demo/src/test/java/com/example/demo/dao/
- รัน: cd demo แล้ว mvnw.cmd test
- ผลดิบอยู่ที่ demo/target/surefire-reports/
- อ้างอิง test cases และข้อมูลตั้งต้น: T12.md
