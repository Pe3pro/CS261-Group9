U3:T11 Design Unit Test Cases ส่วน UI
-
User story U3: นักศึกษายื่นคำร้องขอฝึกสหกิจศึกษาแบบออนไลน์

ขอบเขต
-
- ทดสอบหน้า FillFormView (fillForm · frontend/submit.html) ตามเอกสาร Unit Test ระบบสหกิจศึกษา
- เครื่องมือ: JUnit 5 + Selenium หรือ Playwright · จำลอง API ด้วย mock server
- API ที่หน้านี้เรียก: GET /api/forms/published, POST /api/requests, PUT /api/requests/{id}/form, POST /api/requests/{id}/documents, POST /api/requests/{id}/submit, GET /api/requests/{id}, GET /api/requests/me
- สถานะคำร้อง: DRAFT → SUBMITTED → ADVISOR_REVIEW → APPROVED · ส่งกลับเป็น CORRECTION_REQUIRED · ปฏิเสธเป็น REJECTED

Test cases (ตามเอกสาร Unit Test)
-
| Test ID | ฟังก์ชัน | ขั้นตอนทดสอบ | ผลลัพธ์ที่คาดหวัง |
|---|---|---|---|
| U3-UI-01 | หน้าคำร้อง | นักศึกษาที่ผ่านเกณฑ์เปิด FillFormView | แสดงแบบฟอร์มที่เผยแพร่ล่าสุด (GET /api/forms/published) พร้อมข้อมูลนักศึกษากรอกไว้ล่วงหน้า (รหัส คณะ สาขา เกรดเฉลี่ย แก้ไขไม่ได้) |
| U3-UI-02 | กรอกข้อมูล | กดส่งโดยเว้นช่องบังคับ (ชื่อ เบอร์โทร อีเมล ที่อยู่ หรือกรอกแค่เว้นวรรค) | ระบุทุกช่องที่ต้องกรอก และไม่เรียก API ส่งคำร้อง (ไม่มี request ไปที่ mock server) |
| U3-UI-03 | กรอกข้อมูล | กรอกเบอร์โทร (12ab) หรืออีเมล (somchai@) ผิดรูปแบบ | แจ้งเตือนที่ช่องนั้นให้แก้ไข |
| U3-UI-04 | บันทึกร่าง | กรอกข้อมูลบางส่วน กดบันทึกร่างแล้วปิดหน้า แล้วเปิดใหม่ | ข้อมูลที่กรอกไว้ยังอยู่ครบ |
| U3-UI-05 | Upload PDF | เลือกไฟล์ transcript.docx หรือ photo.jpg | ปฏิเสธไฟล์และแจ้งว่ารับเฉพาะ PDF |
| U3-UI-06 | ส่งคำร้อง | ข้อมูลครบ แนบ transcript.pdf แล้วกดส่ง | ขอให้ยืนยันก่อนส่ง แล้วแสดงว่าส่งสำเร็จพร้อมสถานะ SUBMITTED |
| U3-UI-07 | กดซ้ำ | กดส่งคำร้องหลายครั้งติดกัน | ปุ่มถูกปิดระหว่างรอ และเกิดคำร้องเพียงฉบับเดียว (เรียก submit แค่ครั้งเดียว) |
| U3-UI-08 | แก้ไขคำร้อง | เปิดคำร้องสถานะ CORRECTION_REQUIRED | แสดงเหตุผลจากเจ้าหน้าที่ และเปิดให้แก้ไขและส่งใหม่ได้ |
