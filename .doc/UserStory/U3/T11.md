U3:T11 Design Unit Test Cases ส่วน UI
-
User story U3: นักศึกษายื่นคำร้องขอฝึกสหกิจศึกษาแบบออนไลน์

Test cases
-
| TC ID | สิ่งที่ทดสอบ | Input | Expected result |
|---|---|---|---|
| UI-01 | ยื่นสำเร็จ (TC1) | กรอกข้อมูลครบ แนบ transcript.pdf แล้วกดปุ่มส่งคำร้องเพื่อตรวจสอบ | ไม่มีข้อความแจ้งเตือน แสดงหน้ากำลังตรวจสอบ แล้วไปหน้าผลการยื่นคำร้อง แถบผลเป็นสีเขียว และมีปุ่มไปจับคู่บริษัท |
| UI-02 | ไม่กรอกชื่อ (TC2) | ช่องชื่อ-นามสกุลว่าง ช่องอื่นครบ | ขึ้นข้อความ "กรุณากรอกข้อมูลที่จำเป็นให้ครบ" และยังอยู่หน้ากรอกข้อมูล |
| UI-03 | ไม่กรอกเบอร์โทร | ช่องเบอร์โทรศัพท์ว่าง | เหมือน UI-02 |
| UI-04 | ไม่กรอกอีเมล | ช่องอีเมลว่าง | เหมือน UI-02 |
| UI-05 | ไม่กรอกที่อยู่ | ช่องที่อยู่ปัจจุบันว่าง | เหมือน UI-02 |
| UI-06 | กรอกแต่ช่องว่าง | ช่องชื่อ-นามสกุลกรอกแค่เว้นวรรค | เหมือน UI-02 (ต้อง trim) |
| UI-07 | อีเมลผิดรูปแบบ | อีเมล somchai@ | ขึ้นข้อความแจ้งว่าอีเมลไม่ถูกต้อง และไม่ส่งคำร้อง |
| UI-08 | เบอร์โทรผิดรูปแบบ | เบอร์โทร 12ab | ขึ้นข้อความแจ้งว่าเบอร์โทรไม่ถูกต้อง และไม่ส่งคำร้อง |
| UI-09 | ไม่แนบ Transcript | กรอกข้อมูลครบ แต่ไม่แนบไฟล์ | แถบผลเป็นสีแดง หัวข้อเอกสาร Transcript แจ้งว่าไม่พบไฟล์ มีปุ่มแก้ไขข้อมูลและปุ่มตรวจสอบอีกครั้ง ไม่มีปุ่มไปจับคู่บริษัท |
| UI-10 | ไฟล์ไม่ใช่ PDF | แนบไฟล์ photo.exe | แจ้งว่า Transcript ต้องเป็นไฟล์ PDF และไม่มีปุ่มไปจับคู่บริษัท |
| UI-11 | กดแก้ไขข้อมูล | หลังจาก UI-09 กดปุ่มแก้ไขข้อมูล | กลับไปหน้ากรอกข้อมูล ข้อมูลที่กรอกไว้ยังอยู่ครบ และแถบขั้นตอนกลับไปขั้นที่ 1 |
| UI-12 | กดตรวจสอบอีกครั้ง | หลังจาก UI-09 แนบไฟล์แล้วกดปุ่มตรวจสอบอีกครั้ง |ระบบตรวจใหม่ตามไฟล์ล่าสุด |
| UI-13 | ข้อมูลจากระบบ | เปิดหน้ายื่นคำร้อง | ช่องรหัสนักศึกษา คณะ สาขาวิชา และเกรดเฉลี่ย มีค่าเติมไว้แล้วและแก้ไขไม่ได้ |
| UI-14 | **ยื่นซ้ำ (TC3)** | จำลองให้ API ตอบกลับว่ามีคำร้องที่อยู่ระหว่างดำเนินการแล้ว (409) | แถบผลเป็นสีแดง ข้อความ "คุณมีคำร้องประเภทนี้ที่อยู่ระหว่างดำเนินการแล้ว" ไม่มีปุ่มไปจับคู่บริษัทและปุ่มแก้ไขข้อมูล |
| UI-15 | **ยื่นหลังหมดเขต (TC4)** | จำลองให้ API ตอบกลับว่าเกินกำหนดเวลา (422) | แถบผลเป็นสีแดง ข้อความ "เกินระยะเวลาที่กำหนด ไม่สามารถยื่นคำร้องได้" ไม่มีปุ่มไปจับคู่บริษัท ปุ่มแก้ไขข้อมูล และปุ่มตรวจสอบอีกครั้ง |
| UI-16 | กดส่งซ้ำรัว ๆ | กดปุ่มส่งคำร้อง 2 ครั้งติดกัน | ส่งไปที่ API แค่ครั้งเดียว |
| UI-17 | ไปหน้าถัดไป | หลังจาก UI-01 กดปุ่มไปจับคู่บริษัท | ไปหน้าจับคู่บริษัท และเมนูจับคู่บริษัทกดได้ |
| UI-18 | ยกเลิก | กดปุ่ม "ยกเลิก" | กลับไปหน้าตรวจสอบคุณสมบัติ |
