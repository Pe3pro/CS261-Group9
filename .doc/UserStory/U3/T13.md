U3:T13 Design Integration Test ระหว่าง UI กับ API
-
User story U3: นักศึกษายื่นคำร้องขอฝึกสหกิจศึกษาแบบออนไลน์

ขอบเขต
-
- ทดสอบ FillFormView (frontend/submit.html) เรียก API จริง ตามเส้นทาง View → Controller → Service → DAO → ฐานข้อมูล ใน Sequence Diagram
- เครื่องมือ: backend รันด้วย Docker (PostgreSQL ทดสอบ) จำลองเฉพาะบริการภายนอก (TUAPI, Email)
- API ที่เกี่ยวข้อง: GET /api/forms/published, POST /api/requests, PUT /api/requests/{id}/form, POST /api/requests/{id}/documents, POST /api/requests/{id}/submit, GET /api/requests/{id}, GET /api/requests/me
- วิธีตรวจ: เปิด DevTools แท็บ Network ดู request ที่หน้าเว็บส่ง ดูการแสดงผลบนหน้าจอ และตรวจข้อมูลในฐานข้อมูล
- U3-INT-01, U3-INT-02 และ U3-INT-04 เป็นเคสเดียวกับใน T14.md แต่เริ่มจากหน้าเว็บ
