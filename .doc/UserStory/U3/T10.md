เทียบ Sequence Diagram กับโค้ดที่รวมแล้ว
-
| ขั้นใน Sequence Diagram | Component / ไฟล์ | หลักฐาน |
|---|---|---|
| Student login แล้วหน้าเว็บรู้ userId | `login.html` + `js/login.js` (U1) · ทุก request ของ U3 ส่ง header `X-User-Id` (ไม่ส่ง = 401) | รูป A |
| เปิดหน้ายื่นคำร้อง โหลดแบบฟอร์ม ข้อมูลนักศึกษา และคำร้องเดิม | `submit.html` + `js/script.js` (`initSubmit` → `loadState`) → `GET /api/forms/published`, `GET /api/students/me`, `GET /api/requests/me` → `RequestController` → `RequestService` → `FormTemplateRepository`, `StudentRepository`, `ApplicationRepository` | รูป A |
| Submit application → `POST /api/applications` (ปัจจุบัน `POST /api/requests`) | `send()` ใน `script.js` (ถามยืนยันก่อนส่ง และปิดปุ่มระหว่างรอ) → `RequestController.create()` → `RequestService.create()` | รูป B |
| validate and submit → save application → INSERT application | `RequestService.create()` ตรวจคำร้องค้าง (ยื่นซ้ำ → 409) → `ApplicationRepository.save` สถานะ DRAFT · `PUT /api/requests/{id}/form` → `RequestService.saveAnswers()` ตรวจช่องบังคับ/รูปแบบ (ผิด → 400 พร้อมรายชื่อช่อง) → `FormResponseRepository.save` | รูป B, ตาราง applications / form_responses |
| ตอบ Application ID | `RequestResponse` (id, status) | DevTools Network |
| Upload PDF → `POST /api/documents` (ปัจจุบัน `POST /api/requests/{id}/documents`) | `RequestController.upload()` → `DocumentService.upload()` ตรวจนามสกุล ขนาด และเนื้อไฟล์ต้องเป็น PDF (ผิด → 400) | รูป B |
| Store PDF → Storage key | `FileStorage.store()` (`LocalFileStorage` โฟลเดอร์ `app.upload-dir`) | ไฟล์ในโฟลเดอร์ uploads |
| Save document metadata → INSERT document | `DocumentRepository.saveAndFlush(Document(applicationId, fileName, storageKey, size))` · บันทึกไม่สำเร็จ → ลบไฟล์ที่เก็บไปแล้ว ไม่มี metadata ค้าง | ตาราง documents |
| ยื่นจริง `POST /api/requests/{id}/submit` | `RequestService.submit()` ตรวจ deadline (หมดเขต → 409 DEADLINE_PASSED), ต้องแนบ PDF (ไม่แนบ → 400), สถานะต้องเป็น DRAFT หรือ CORRECTION_REQUIRED → SUBMITTED และบันทึก submittedAt | รูป C |
| Send notification / Email result | `EmailNotifier.send()` ("ได้รับคำร้องขอฝึกสหกิจศึกษาแล้ว") · ตอนนี้ใช้ `LoggingEmailNotifier` เขียนบรรทัด `[EMAIL] to=...` ลง log ของ backend | docker compose logs app |
| เจ้าหน้าที่เห็นคำร้อง (U5) | `staff-review.html` → `GET /api/applications?status=SUBMITTED` · เปิดไฟล์ `GET /api/documents/{id}` → `DocumentController` → `DocumentService.download()` | รูป D |
| ผิดพลาดทุกขั้น → `ApiException` / `FieldValidationException` → `ApiExceptionHandler` → `ErrorResponse(code, message)` | หน้าเว็บแสดงแถบผลสีแดงพร้อมข้อความ | รูป E, F |

ข้อมูลในฐานข้อมูลหลังรัน (MySQL)
-
```sql
SELECT id, student_id, status, submitted_at FROM applications;
SELECT application_id, COUNT(*) FROM form_responses GROUP BY application_id;
SELECT application_id, file_name, storage_key, size FROM documents;
```

| ตาราง | ที่ต้องเห็น |
|---|---|
| applications | คำร้องของ 6609650003 สถานะ SUBMITTED มี submitted_at |
| form_responses | คำตอบครบทุกช่องของแบบฟอร์ม ผูกกับคำร้องเดียวกัน |
| documents | transcript.pdf 1 แถว มี storage_key ผูกกับคำร้องเดียวกัน |
