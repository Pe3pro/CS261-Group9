เตรียมระบบสำหรับ UAT
-
1. docker compose down -v แล้ว docker compose up -d --build (ฐานข้อมูลใหม่จาก DemoDataSeeder)
2. เปิด frontend/login.html ด้วย Live Server
3. P4 (staff01) ปฏิเสธคำร้องเดิมของ 6609650001 ในหน้า staff-review เพื่อให้ P3 ยื่นใหม่ได้ (คำร้อง REJECTED ยื่นใหม่ได้)
4. หน้าตรวจสอบคุณสมบัติ (U2) ต้องผ่านก่อน จึงเข้าหน้ายื่นคำร้องได้
5. scenario ที่ผู้ทดสอบทำเองไม่ได้:
   - UAT-02 (ส่งกลับให้แก้): หลัง P1 ยื่นสำเร็จ ให้ P4 เปิดคำร้องในหน้า staff-review แล้วเลือก "ส่งกลับแก้ไข" พร้อมเหตุผล
   - UAT-04 (หมดเขต): P4 สร้างแบบฟอร์มใหม่ในหน้า staff-forms ตั้งวันหมดเขตอีก 2–3 นาที แล้วเปิดใช้งาน รอให้เลยเวลาก่อนให้ P2 เริ่ม · ทำ UAT-04 เป็นข้อสุดท้าย และหลังจบต้องเปิดแบบฟอร์มใหม่ที่ยังไม่หมดเขต
6. Email ยังไม่มี mail server จริง ดูข้อความที่ระบบส่งได้จาก docker compose logs app (บรรทัด [EMAIL])

ลำดับการทดสอบ: UAT-01 (P1, P2, P3) → UAT-02 → UAT-03 → UAT-05 → UAT-04
