เตรียมระบบสำหรับ UAT
-
1. docker compose down -v แล้ว docker compose up -d --build (ฐานข้อมูลใหม่จาก DemoDataSeeder)
2. เปิด frontend/login.html ด้วย Live Server
3. บัญชีทดลอง (รหัสผ่าน 1234): นักศึกษาที่ยังไม่มีคำร้อง 6609650003, 6609650004 · นักศึกษาที่มีคำร้องอยู่แล้ว 6609650001, 6609650002 · เจ้าหน้าที่ staff01
   ถ้ามีผู้ทดสอบมากกว่า 2 คนสำหรับ UAT-01 ให้ล้างฐานข้อมูล (ข้อ 1) ระหว่างรอบ หรือให้เจ้าหน้าที่ปฏิเสธคำร้องเดิมก่อน (คำร้อง REJECTED ยื่นใหม่ได้)
4. หน้าตรวจสอบคุณสมบัติ (U2) ต้องผ่านก่อนจึงเข้าหน้ายื่นคำร้องได้
5. เตรียม scenario ที่ผู้ทดสอบทำเองไม่ได้:
   - UAT-02 (ส่งกลับให้แก้): เจ้าหน้าที่ P4 เปิดคำร้องในหน้า staff-review แล้วเลือก "ส่งกลับแก้ไข" พร้อมเหตุผล
   - UAT-03 (ยื่นซ้ำ): ให้ผู้ทดสอบใช้บัญชี 6609650002 หรือบัญชีที่เพิ่งยื่นสำเร็จใน UAT-01
   - UAT-04 (หมดเขต): เจ้าหน้าที่สร้างแบบฟอร์มใหม่ในหน้า staff-forms ตั้งวันหมดเขตอีก 2–3 นาทีแล้วเปิดใช้งาน รอให้เลยเวลาก่อนให้ผู้ทดสอบเริ่ม
     หลัง UAT-04 ต้องเปิดแบบฟอร์มใหม่ที่ยังไม่หมดเขต ก่อนทดสอบ TC อื่นต่อ
6. Email ยังไม่มี mail server จริง ดูข้อความที่ระบบส่งได้จาก docker compose logs app (บรรทัด [EMAIL])
