U3:T12 Design Unit Test Cases ส่วน DAO

User story U3: นักศึกษายื่นคำร้องขอฝึกสหกิจศึกษาแบบออนไลน์

ขอบเขต
ทดสอบ Repository (DAO) ที่ U3 ใช้ ตาม DAO Class Diagram ใน T6 ได้แก่ ApplicationRepository, FormTemplateRepository, FormResponseRepository, DocumentRepository และ StudentRepository
วิธีทดสอบ: ใช้ @DataJpaTest กับฐานข้อมูล H2 ในหน่วยความจำ ทุก test ล้างข้อมูลคืนอัตโนมัติ ไม่ต้องต่อ PostgreSQL จริง

ข้อมูลตั้งต้น
-
| ชื่อ | ค่า |
|---|---|
| นักศึกษา A | studentId 1, รหัส 6609650001, ยังไม่มีคำร้อง |
| นักศึกษา B | studentId 2, รหัส 6609650002, มีคำร้องสถานะ SUBMITTED |
| นักศึกษา C | studentId 3, รหัส 6609650003, มีคำร้องสถานะ REJECTED |
| ฟอร์ม F1 | formTemplateId 10, สถานะ PUBLISHED, version 1 |
| ฟอร์ม F2 | formTemplateId 11, สถานะ DRAFT, version 2 |

Test cases
-
| TC ID | สิ่งที่ทดสอบ | Input | Expected result |
|---|---|---|---|
| DAO-A01 | บันทึกคำร้องใหม่ (TC1) (ApplicationRepository.save, findById) | Application ของนักศึกษา A ฟอร์ม F1 สถานะ SUBMITTED มี submittedAt | ได้ id ใหม่ ค้นกลับด้วย id ได้ข้อมูลตรงทุกช่อง |
| DAO-A02 | ค้นคำร้องที่ไม่มีอยู่ (ApplicationRepository.findById) | id 999999 | ได้ค่าว่าง |
| DAO-A03 | **ค้นคำร้องของนักศึกษาที่มีคำร้องค้าง (TC3)** (ApplicationRepository.findByStudentId) | studentId 2 | ได้ 1 รายการ สถานะ SUBMITTED ให้ Service ใช้ตัดสินว่ายื่นซ้ำ |
| DAO-A04 | **นักศึกษาที่ยังไม่เคยยื่น (TC3)** (ApplicationRepository.findByStudentId) | studentId 1 | ได้รายการว่าง ยื่นได้ |
| DAO-A05 | **นักศึกษาที่เคยถูกปฏิเสธ (TC3)** (ApplicationRepository.findByStudentId) | studentId 3 | ได้ 1 รายการ สถานะ REJECTED ไม่นับเป็นยื่นซ้ำ |
| DAO-A06 | ไม่ปนข้อมูลของคนอื่น (ApplicationRepository.findByStudentId) | studentId 2 | ทุกรายการที่ได้เป็นของ studentId 2 เท่านั้น |
| DAO-A07 | ค้นตามสถานะ (ApplicationRepository.findByStatus) | SUBMITTED | ได้เฉพาะคำร้องสถานะ SUBMITTED ของนักศึกษา B |
| DAO-A08 | แก้ไขคำร้องที่ถูกส่งกลับ (TC2) (ApplicationRepository.save) | คำร้องสถานะ NEED_CORRECTION แก้แล้วเปลี่ยนเป็น SUBMITTED | id เดิม สถานะใหม่ถูกบันทึก และ updatedAt เปลี่ยน |
| DAO-A09 | บันทึกโดยไม่มี studentId (ApplicationRepository.save) | Application ที่ studentId ว่าง | ถูกปฏิเสธ เกิด DataIntegrityViolationException |
| DAO-F01 | ค้นฟอร์มที่เปิดใช้งาน (FormTemplateRepository.findByStatus) | PUBLISHED | ได้ฟอร์ม F1 เท่านั้น |
| DAO-F02 | ค้นฟอร์มตาม version (FormTemplateRepository.findByVersion) | 2 | ได้ฟอร์ม F2 |
| DAO-F03 | ค้น version ที่ไม่มี (FormTemplateRepository.findByVersion) | 99 | ได้ค่าว่าง |
| DAO-F04 | **อ่านวันหมดเขตของฟอร์ม (TC4)** (FormTemplateRepository.findById) | formTemplateId 10 | ได้วันหมดเขตตรงตามที่บันทึก ไม่เพี้ยนเพราะ timezone |
| DAO-R01 | บันทึกคำตอบในฟอร์ม (TC1) (FormResponseRepository.save, findByApplicationId) | คำตอบ 4 ช่อง (ชื่อ เบอร์โทร อีเมล ที่อยู่) ของคำร้องนักศึกษา B | ค้นด้วย applicationId ได้ครบ 4 รายการ |
| DAO-R02 | แก้ไขคำตอบ (TC2) (FormResponseRepository.save) | เปลี่ยนเบอร์โทรเป็น 0899999999 | ค่าใหม่ถูกบันทึก ไม่เกิดรายการซ้ำ |
| DAO-D01 | บันทึกเอกสาร Transcript (DocumentRepository.save, findByApplicationId) | transcript.pdf ของคำร้องนักศึกษา B | ค้นด้วย applicationId ได้ 1 รายการ ชื่อไฟล์และขนาดตรง |
| DAO-D02 | คำร้องที่ยังไม่แนบไฟล์ (DocumentRepository.findByApplicationId) | คำร้องที่ไม่มีเอกสาร | ได้รายการว่าง |
| DAO-S01 | ค้นนักศึกษาจากรหัส (StudentRepository.findByStudentId) | 6609650001 | ได้ข้อมูลนักศึกษา A (คณะ สาขา GPA) ใช้เติมในหน้ายื่นคำร้อง |
| DAO-S02 | รหัสที่ไม่มีในระบบ (StudentRepository.findByStudentId) | 0000000000 | ได้ค่าว่าง |
