U3:T12 Design Unit Test Cases ส่วน DAO

User story U3: นักศึกษายื่นคำร้องขอฝึกสหกิจศึกษาแบบออนไลน์

ขอบเขต
-
- ทดสอบ Repository (DAO) ที่ U3 ใช้ตามเอกสาร Unit Test ได้แก่ RequestRepository, FormAnswerRepository และ DocumentRepository
- วิธีทดสอบ: @DataJpaTest + PostgreSQL ใน Docker ไม่จำลองฐานข้อมูล ใช้ฐานข้อมูลจริงในคอนเทนเนอร์ ทุก test ล้างข้อมูลคืนอัตโนมัติ

ข้อมูลตั้งต้น
-
| ชื่อ | ค่า |
|---|---|
| นักศึกษา A | student_id 1, รหัส 6609650001, ยังไม่มีคำร้อง |
| นักศึกษา B | student_id 2, รหัส 6609650002, มีคำร้องสถานะ SUBMITTED |
| ฟอร์ม F1 | form_id 10, สถานะ PUBLISHED มี 4 ช่อง (ชื่อ เบอร์โทร อีเมล ที่อยู่) |
| ไฟล์ | transcript.pdf ขนาด 512000 bytes |

Test cases (ตามเอกสาร Unit Test)
-
| Test ID | Repository | กรณีทดสอบ | Input | ผลลัพธ์ที่คาดหวัง |
|---|---|---|---|---|
| U3-DAO-01 | RequestRepository | บันทึกคำร้องใหม่ | คำร้องของนักศึกษา A ฟอร์ม F1 | ได้ ID สถานะ DRAFT และ student_id ถูกต้อง (1) |
| U3-DAO-02 | RequestRepository | findById ด้วย ID ที่มีอยู่ | ID คำร้องของนักศึกษา B | คืนคำร้องพร้อมคำตอบแบบฟอร์ม |
| U3-DAO-03 | RequestRepository | findById ด้วย ID ที่ไม่มีอยู่ | 999999 | คืน Optional.empty |
| U3-DAO-04 | RequestRepository | findByStudentId | student_id 2 | คืนเฉพาะคำร้องของนักศึกษาคนนั้น |
| U3-DAO-05 | RequestRepository | บันทึกคำร้องที่อ้าง student_id ที่ไม่มีอยู่ | student_id 999 | Foreign Key ปฏิเสธ (DataIntegrityViolationException) |
| U3-DAO-06 | FormAnswerRepository | บันทึกคำตอบหลายช่องแล้วอ่านกลับ | คำตอบ 4 ช่องของคำร้องนักศึกษา B | ได้คำตอบครบและตรงกับช่องของแบบฟอร์ม |
| U3-DAO-07 | DocumentRepository | บันทึก metadata ของ PDF | transcript.pdf ของคำร้องนักศึกษา B | มีชื่อไฟล์ ขนาด ที่เก็บไฟล์ และผูกกับคำร้องถูกต้อง |
| U3-DAO-08 | RequestRepository | ค้นหาด้วยค่าที่มีอักขระพิเศษ | `' OR '1'='1` และ `1; DROP TABLE requests;--` | ไม่เกิด SQL Injection ได้ผลว่าง และตาราง requests ยังอยู่ครบ |
