API Specification
-
ผู้เรียก API ระบุตัวตนด้วย header X-User-Id (ไม่ส่ง = 401) · ตรงกับโค้ดใน demo/src/main/java/com/example/demo/controller/RequestController.java

| Method | Endpoint | หน้าที่ |
|---|---|---|
| GET | /api/forms/published | โหลดฟอร์มและ deadline |
| GET | /api/students/me | ดึงข้อมูลนักศึกษา |
| GET | /api/requests/me | เช็กว่าเคยยื่นไว้หรือยัง |
| POST | /api/requests | สร้างคำร้อง (DRAFT) |
| PUT | /api/requests/{id}/form | บันทึกคำตอบในฟอร์ม |
| POST | /api/requests/{id}/documents | แนบ Transcript (PDF) |
| POST | /api/requests/{id}/submit | ยื่นจริง (ตรวจ deadline, PDF และการยื่นซ้ำ) |
| GET | /api/requests/{id} | ดูผลและสถานะคำร้อง |
