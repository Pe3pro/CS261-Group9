U3:T16 Design User Acceptance Test ตาม user story details
-
User story U3
As a : นศ.มธ. ที่ต้องการยื่นคำร้องขอฝึกสหกิจศึกษา
I want to : ยื่นคำร้องขอฝึกสหกิจศึกษาแบบออนไลน์
So that : สามารถสร้างคำร้องและยื่นได้ในระบบ โดยส่งไปถึงผู้ที่เกี่ยวข้องได้อย่างถูกต้องครบถ้วน

ขอบเขต
-
- ผู้ทดสอบ: นักศึกษาจริง 3–5 คน และเจ้าหน้าที่ 1 คน
- ทดสอบบนระบบที่รันครบทุกส่วน ทีมไม่ช่วยบอกขั้นตอนระหว่างทดสอบ ให้ผู้ทดสอบทำเองจากหน้าจอ
- ทีมจดเวลา ปัญหาที่เจอ และ feedback ของผู้ทดสอบ

Test cases
-
| TC ID | Scenario | Given | When | Then | เกณฑ์ผ่านที่ user ยอมรับได้ |
|---|---|---|---|---|---|
| UAT-01 | ยื่นสำเร็จ (TC1) | นักศึกษาผ่านการตรวจคุณสมบัติแล้วและยังไม่เคยยื่น | กรอกข้อมูลครบ แนบ Transcript แล้วกดส่ง | เห็นข้อความยืนยันพร้อมเลขที่คำร้อง และเจ้าหน้าที่เห็นคำร้องในระบบ | ทำเองได้จนจบภายใน 5 นาที ข้อมูลที่เจ้าหน้าที่เห็นตรงกับที่กรอกทุกช่อง |
| UAT-02 | ข้อมูลตกหล่นหรือผิดพลาด (TC2) | นักศึกษากรอกไม่ครบ หรือคำร้องถูกเจ้าหน้าที่ส่งกลับให้แก้ | แก้ข้อมูลแล้วส่งใหม่ก่อนหมดเขต | ส่งได้และเจ้าหน้าที่เห็นข้อมูลฉบับล่าสุด | รู้ทันทีว่าต้องแก้ช่องไหน ข้อมูลที่กรอกไว้แล้วไม่หาย ไม่ต้องกรอกใหม่ทั้งหมด |
| UAT-03 | **ยื่นซ้ำ (TC3)** | นักศึกษามีคำร้องประเภทเดียวกันอยู่ระหว่างดำเนินการ | เข้าหน้ายื่นคำร้องและพยายามยื่นอีกครั้ง | ระบบแจ้งเตือนและไม่ให้ยื่น | อ่านแล้วเข้าใจว่าทำไมยื่นไม่ได้และต้องทำอะไรต่อ เจ้าหน้าที่ไม่เห็นคำร้องซ้ำในระบบ |
| UAT-04 | **ยื่นหลังหมดเขต (TC4)** | เลยวันและเวลาที่กำหนดแล้ว | กรอกข้อมูลครบแล้วกดส่ง | ระบบไม่ให้ส่งและแจ้งว่าเกินระยะเวลาที่กำหนด | ข้อความบอกวันหมดเขตชัดเจน และไม่มีทางส่งผ่านได้ไม่ว่าจะลองกี่ครั้ง |
| UAT-05 | เจ้าหน้าที่ได้รับคำร้องครบถ้วน | นักศึกษายื่นคำร้องสำเร็จแล้ว | เจ้าหน้าที่เปิดดูคำร้อง | เห็นข้อมูลนักศึกษาครบ และเปิดไฟล์ Transcript ได้ | เจ้าหน้าที่ไม่ต้องติดต่อนักศึกษาเพื่อขอข้อมูลเพิ่ม |

เกณฑ์ผ่าน UAT โดยรวม
-
- UAT-01 ถึง UAT-04 ต้องผ่านทุกข้อ เพราะเป็นเคสบังคับตาม user story
- ผู้ทดสอบอย่างน้อย 80% ทำ UAT-01 สำเร็จเองโดยไม่ต้องถามทีม
- ไม่มีปัญหาที่ทำให้ยื่นคำร้องไม่ได้ค้างอยู่
