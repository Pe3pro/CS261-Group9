U3:T14 Design Integration Test ระหว่าง API กับ DAO
-
User story U3: นักศึกษายื่นคำร้องขอฝึกสหกิจศึกษาแบบออนไลน์

ขอบเขต
-
- ทดสอบการทำงานต่อกันของ RequestController → RequestService / DocumentService → RequestRepository / FormAnswerRepository / DocumentRepository → ฐานข้อมูล
- เครื่องมือ: @SpringBootTest + MockMvc + Docker (PostgreSQL ทดสอบ) ล้างข้อมูลก่อนเริ่มทุกข้อ
- จำลองเฉพาะบริการภายนอก (TUAPI, Email) และที่เก็บไฟล์ในกรณี U3-INT-03
- การกำหนดเวลา: ส่ง Clock เข้า RequestService เพื่อกำหนด "เวลาปัจจุบัน" ใน test ได้ (ใช้ทดสอบหมดเขต)
