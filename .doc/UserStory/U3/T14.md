U3:T14 Design Integration Test ระหว่าง API กับ DAO
-
User story U3: นักศึกษายื่นคำร้องขอฝึกสหกิจศึกษาแบบออนไลน์

ขอบเขต
-
- ทดสอบการทำงานต่อกันของ ApplicationController → ApplicationService → ApplicationRepository / FormTemplateRepository / DocumentRepository → ฐานข้อมูล
- ไม่ใช้หน้าเว็บ ส่ง request ด้วย Postman หรือ MockMvc (@SpringBootTest) แล้วตรวจข้อมูลในฐานข้อมูลผ่าน Repository
- ฐานข้อมูลทดสอบ: H2 หรือ PostgreSQL ทดสอบ ล้างข้อมูลก่อนเริ่มทุกข้อ
- การกำหนดเวลา: ส่ง Clock เข้า ApplicationService เพื่อกำหนด "เวลาปัจจุบัน" ใน test ได้ (ใช้ทดสอบหมดเขต)

ข้อมูลตั้งต้น
-
| ชื่อ | ค่า |
|---|---|
| นักศึกษา A | studentId 1, ยังไม่มีคำร้อง |
| นักศึกษา B | studentId 2, มีคำร้องสถานะ SUBMITTED ของฟอร์ม F1 |
| นักศึกษา C | studentId 3, มีคำร้องสถานะ REJECTED ของฟอร์ม F1 |
| นักศึกษา D | studentId 4, มีคำร้องสถานะ NEED_CORRECTION ของฟอร์ม F2 |
| ฟอร์ม F1 | formTemplateId 10, หมดเขต 30 พ.ย. 2569 เวลา 23:59:59 |
| ฟอร์ม F2 | formTemplateId 11, หมดเขต 1 ต.ค. 2569 เวลา 23:59:59 (หมดเขตแล้ว) |
| ข้อมูลครบ | คำตอบ 4 ช่อง: ชื่อ สมชาย ใจดี, เบอร์โทร 0812345678, อีเมล somchai@dome.tu.ac.th, ที่อยู่ 99 ม.ธ. รังสิต |
