วิธีทดสอบ
-
- รัน: cd demo → mvnw.cmd spring-boot:run · Base URL: http://localhost:8080
- Import ไฟล์ postman/U3-Application.postman_collection.json แล้วกด Run collection
- ข้อมูลตั้งต้น: นศ. A (ไม่มีคำร้อง), นศ. B (มี SUBMITTED), ฟอร์ม F1 (ยังไม่หมดเขต), F2 (หมดเขตแล้ว)
  ตาม TestCases-README.md
- ทุก request ในหมวด Tests ของ Postman ตรวจ status code และ field ใน response
