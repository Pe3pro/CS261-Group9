วิธีทดสอบ
-
- Controller / API: JUnit 5 + MockMvc (หรือ Postman) จำลอง RequestService และ DocumentService ด้วย Mockito
- Service: JUnit 5 + Mockito จำลอง Repository, TUAPI, ที่เก็บไฟล์ และ Email
- รัน: cd demo → mvnw.cmd test · ผลดิบอยู่ที่ demo/target/surefire-reports/
- Endpoint: GET /api/forms/published, POST /api/requests, PUT /api/requests/{id}/form, POST /api/requests/{id}/documents, POST /api/requests/{id}/submit, GET /api/requests/{id}, GET /api/requests/me
- ข้อมูลตั้งต้น: นศ. A (ผ่านเกณฑ์ ไม่มีคำร้อง), นศ. B (มีคำร้อง SUBMITTED), นศ. X (ยังไม่ผ่านเกณฑ์), ฟอร์ม F1 (PUBLISHED ยังไม่หมดเขต), F2 (หมดเขตแล้ว)
