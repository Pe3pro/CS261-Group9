ขั้นตอนการรัน
-
1. รัน docker-compose up ให้ backend และฐานข้อมูลทำงาน
2. ใส่ข้อมูลตั้งต้น (นักศึกษา A, B, C, เจ้าหน้าที่ S และฟอร์ม F1, F2) ตาม T13.md
3. เปิด frontend/login.html แล้ว login ตามนักศึกษาที่ test case กำหนด
4. เปิด DevTools แท็บ Network ไว้ตลอด เพื่อตรวจ request และ response
5. ทำตาม Input ของแต่ละ test case แล้วบันทึกผลในตารางด้านล่าง
6. ถ้าไม่ผ่าน แคปหน้าจอแท็บ Network และหน้าเว็บเก็บไว้เป็นหลักฐาน
